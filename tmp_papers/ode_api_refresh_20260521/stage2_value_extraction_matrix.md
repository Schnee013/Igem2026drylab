## ODE Modeling Recommendations

### Parameters or structures that can be fixed now

- Yeast pathway module ordering and state-variable categories can be fixed from Shaw 2019, Kofahl 2004/BioModels, and Yi 2003.
- Reporter model definitions such as Hill fitting, LOD/LOQ definitions, and output-layer categories can be fixed from Fan 2024/FanC 2023/Miettinen 2022, but not their project-specific fitted values.
- Docking candidate set can be fixed as scenario labels from the 2026-05-19/2026-05-20 refreshed handoff: primary `Gpr2_R59C + Gpr3_R167Y`, with listed backups.

### Parameters that should be literature priors

- Gpr/Gpa1 chimera coupling efficiency and basal leak: Brown 2000, Ladds 2005, Lengger 2020/2022, Tehseen 2014.
- Reporter amplification and time scale: Shaw 2019, FanC 2023, Fan 2024, Miettinen 2022.
- Identifiability/sensitivity workflow: Simpson & Maclaren 2023, Gutenkunst 2007, Raue 2009.

### Parameters that should be scanned before wet data

- `K_L`/EC50-like ligand half activation: primary log scan `1e-9` to `1e-3` M; optional stress range `1e-12` to `1e-2` M.
- Hill coefficient: `0.5` to `3`.
- Ligand efficacy/coupling efficiency: normalized `1e-3` to `1`.
- Basal leak: normalized `1e-4` to `0.2`.
- Reporter amplification gain: `1` to `100`, depending on direct pFUS1 vs GAL4/sTF design.

### Parameters that must wait for wet-lab calibration

- Project `Kd`, `kon`, `koff`, `EC50/Kc`, `Emax`, Hill, basal leak, receptor expression/localization, and chimeric Gpa1 coupling for each Gpr mutant/ascr pair.
- Single-copy GAL4/sTF gain and reporter time constants under the actual integration locus and chassis edits.
