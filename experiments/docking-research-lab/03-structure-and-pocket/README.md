# 受体结构与口袋比较

比较TWF154 Gpr2/Gpr3与GprC、SRBC-64的跨膜结构，并检查ATCC与TWF154模型差异，为候选口袋位置提供结构依据。

已有六组正式TM-core比对。结果表中Gpr2/Gpr3与GprC的RMSD为1.76/2.02 Å，与SRBC-64为2.65/2.71 Å；TWF154与ATCC对应比较为0.26/0.39 Å。不同覆盖度及归一化TM-score一并保留在原表中。
