# 环境与路径使用说明

当前交付支持按README阅读报告、查找原始结果，以及使用Python标准库运行[交付验证器](../../provenance/verify_delivery.py)。GitHub内容默认检查，完整数据需先按[飞书恢复说明](../../DATA_DELIVERY.md)恢复再使用`--mode full`。验证器按交付根目录解析路径，独立核对文件与来源哈希。

## 原科学流程

[原操作协议](user-run-vina.source.md)记录Vina 1.2.5、Meeko 0.7.1、ProLIF 2.1.0及历史运行分工；[原工具说明](vina.source.md)记录当时工具能力和输入组织。软件是否在接收者机器上安装，需要重新检查。

批次CLI、分析脚本、原配置和PML保留来源版本，其中仍有旧目录名、绝对路径及按原目录层数定位的代码。重新运行需要先创建独立输出目录，按迁移表适配路径，核对依赖及输入，并完成对应批次的预检查。旧README中的命令是历史记录，不能在新目录直接视为已验证命令。

本次没有启动AF、Vina、ProLIF或结构制备，也没有重算报告。科学脚本的可移植改造与端到端运行验收尚待完成；文件一致性校验通过仅确认交付内容及来源。
