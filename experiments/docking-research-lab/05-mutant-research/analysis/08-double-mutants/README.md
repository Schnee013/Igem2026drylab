# 双突变结果与亲本比较

08批完成18个双突变的36组双配体对接，并有最低分pose接触结果。组合按A–F模块设计，复用05/07的14种亲本；05-WT为主参照，07-WT用于敏感性检查。

先读[模块分析](double-mutant-analysis.md)，再查[评分与亲本比较](double-mutant-scores.md)和[组合数据](../data/combination-mutants.json)。执行范围见[设计v3](../../design/combination-plan-v3.md)，逐受体结果见[批次08](../../batches/08-af3-double-mutants/README.md)。

多数组合未超过较好亲本的目标配体评分。N84Y_V368N相对N84Y使两项评分分别降低0.590和0.612，D变化−0.022；相对V368N仍有#18评分取舍。V110S在本轮五种配对背景中的#18评分均低于对应V110C组合，但这一现象的范围限于已测试背景。

完整比较同时保留两项评分、D、两亲本差值、非加和残差和姿态/接触变化。共同WT下的亲本差值不因更换WT而改变；独立AF模型与单次对接限制了机制和实验协同解释。
