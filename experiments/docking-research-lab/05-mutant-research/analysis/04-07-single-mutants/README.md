# 扩展单突变与四位点饱和筛选

04–07汇总99条单突变结构记录、87种设计和4个来源WT。04有17条单点，05有57条，06有6条，07有19条；相同设计在不同批次分别保留。05的N84/V110/V368与07的W338各19种替换，共76种饱和替换。

## 阅读顺序

1. [单突变概览](single-mutant-overview.md)：本次整理的阶段概述与关键例子。
2. [候选作用方式](single-mutant-roles.md)：改善目标、削弱另一配体、共同改善与来源敏感候选。
3. [全部单突变评分](single-mutant-scores.md)：按批次查看具体数值和来源WT。
4. [四位点统计](saturation-statistics.md)与[饱和分析](saturation-analysis.md)：完整面板的描述统计和解释。
5. [候选与WT接触对照](single-mutant-contact-candidates.md)：接触改变及制图建议。

完整数据见[data/single-mutants.json](data/single-mutants.json)，专项核查见[supporting-evidence/](supporting-evidence/)。模型、seed、CPU和哈希保留在数据及运行记录中。原始材料部分链接曾指向`single-mutant-analysis.md`，源目录未提供该文件；本次新增的概览独立标明依据，详细解释以实际存在的报告为准。

本阶段支持[双突变设计](../../design/README.md)。来源WT敏感性和W338C的model_1例外保留；饱和面板的接触频数是设计间检出数，不能解读为动力学占有率。
