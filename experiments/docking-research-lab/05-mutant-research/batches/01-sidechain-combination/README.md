# 批次01 固定骨架侧链组合探索

## 本轮问题与设计

以选定受体骨架为起点，比较两个Ala组合对两种配体评分的影响。

WT、N84A/L90A/R345A三突变、V110A/R181A/W338A/V368A四突变。

## 方法与比较基准

固定骨架侧链替换路线；与AF3重预测路线分别使用各自WT。

两配体采用−1电荷输入；Vina运行记录使用seed=1919，中心(20,−20,5) Å，搜索框26×26×26 Å，exhaustiveness=8，num_modes=9，energy_range=3。本批CPU设置及各次返回码见[逐次运行表](../../run-inventory.csv)。

本批主WT用于ΔS与D；相同设计跨批保留独立记录。 ΔS_i=S_i(突变体)−S_i(WT)，D=ΔS18−ΔS3。负ΔS表示评分降低；正D为相对WT向#3偏移，负D向#18偏移。

## 主要发现与下一轮关系

两个组合的D分别为+0.318、+0.198。三突变对两配体评分均变差；四突变在最低分pose上主要表现为#3略改善。

02批用全长突变序列重新预测结构，比较相同组合在另一种结构准备路线中的表现。

解释与完整比较见[本轮分析入口](../../analysis/01-03-initial-screen/route-comparison/README.md)。最低分pose、接触和静态结构支持计算结果比较；每次搜索中的多个pose不作为独立重复，真实亲和力和功能选择性需要独立证据。
