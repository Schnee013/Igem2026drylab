## 方法概述

- **FoldX BuildModel**: WT TM-only PDB → RepairPDB → BuildModel，~秒/突变
- **受体准备**: ADFR Suite `prepare_receptor.py`
- **对接**: AutoDock Vina 两阶段（Stage1: spacing=0.25Å, box=40Å, exh=32 → Stage2: spacing=0.1Å, box=20Å, exh=200，seed=42）
- **WT 基线**: v2 pipeline 单阶段对接结果（`experiments/docking/results/docking_results.json`）
- **评估对**: ascr#18（PPN 标志物）vs ascr#3（自由生活线虫标志物）
- **ΔΔG 公式**: `ΔΔG_sel = [ΔG_mut(18) − ΔG_WT(18)] − [ΔG_mut(3) − ΔG_WT(3)]`

## ⚠️ 方法学局限性（必读）

### 1. 协议不匹配（最关键）

| | WT（v2 基线） | 突变体（本次扫描） |
|-|-------------|-----------------|
| 网格间距 | 0.25 Å | 0.1 Å（Stage2） |
| box 大小 | 40 Å（全局） | 20 Å（Stage2 精修） |
| exhaustiveness | 200 | Stage1=32 → Stage2=200 |

**后果**: 两阶段 0.1 Å 精修系统性产生更负的亲和力分数。实测偏差约 **−0.7 kcal/mol**（由内部对照确认，见下文）。原始 ΔΔG 中 22/27 突变体显示亲和力"增强"，生物物理上不合理。

### 2. Docking box 灵敏度边界

Stage2 精修 box 仅 20 Å。**位于 box 外的残基突变对计算结果零影响**（网格内受体结构完全相同）。GprC 残基 77 和 83 均在 box 之外（见内部对照节）。

### 3. 刚性受体 + Vina 精度

受体骨架刚性处理，FoldX 仅做局部侧链优化。Vina 评分误差约 ±1 kcal/mol（vs 实验值），ΔΔG < 0.5 kcal/mol 的差异均在噪声范围内。
