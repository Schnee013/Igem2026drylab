# Equal-weight Kabsch regeneration validation

Date: 2026-07-27

## Scope

This record validates the canonical-output regeneration after correcting the
shared MD coordinate transform to:

1. center fit selections by their equal-weight geometric centers;
2. obtain the rotation from `MDAnalysis.analysis.align.rotation_matrix`; and
3. apply that column-vector rotation matrix transposed to row-vector atom
   coordinates.

The regeneration used the current shared driver and the existing processed
trajectory payloads. No production trajectory, processed trajectory, topology,
or raw MD payload was modified or added to Git.

## Regenerated outputs

- chimeric Ste2-Gpa1 WT rep1-rep3:
  `analysis/selection_rmsd/` and the RMSD-derived files in
  `analysis/selection_audit/`;
- Gpr2 WT + ASCR18 rep1: `analysis/selection_rmsd/`, the compact metric summary,
  and the canonical analysis report;
- Gpr3 R167Y + ASCR3 rep1: `analysis/selection_rmsd/`.

Gpr3 R167Y regenerated byte-identically. Its existing historical analysis
validation and checksum files therefore remain valid and were not rewritten.
The Gpr2 WT archive checksum route covers the external MD payload, not these
Git-visible analysis outputs, so it also remains unchanged.

## Validation result

- Input identities are recorded in `input_identity.tsv`. The Gpr2 WT and Gpr3
  R167Y hashes match their versioned payload manifests. The chimeric inputs
  were read from the preserved primary-worktree payload and were opened
  read-only for regeneration.
- CSV schemas, row counts, replicate labels, and time grids match the
  pre-regeneration canonical outputs.
- The generic chimeric selection RMSD and the independently recalculated
  full-protein audit RMSD agree within `1e-6 A`; observed maximum differences
  are below `9e-16 A`.
- The regenerated PNGs were visually inspected for non-empty traces, axes,
  legends, and label integrity.
- `output_validation.tsv` records the old-to-corrected numeric deltas. Those
  deltas are evidence of the repaired transform, not a tolerance failure.
- `canonical_outputs.sha256` pins the regenerated Git-visible output set.

## Scientific boundary

The correction does not change the current project-level interpretation:
chimeric rep1/rep2 retain the alpha5 caveat, rep3 remains pass-like by the
project operational mean band, and both GPR ligand RMSD series remain
descriptive single-replicate structural-triage signals without a
ligand-specific categorical cutoff.
