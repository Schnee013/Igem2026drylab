# Gpr2 TWF154：本轮长期保留文件

按 2026-10-05 用户决定，仅保留六个原始来源组合、两条优先生产的已有结果，以及精简方法与错误记录。六套旧重建版、四套回变 WT 均未纳入；旧 WT–ascr18 的 200 ns 项目保持原位置，本包不处理它。

## 目录怎么用

| 目录 | 内容 |
|---|---|
| `sources/` | TWF154 FASTA、两突变体原始全长 AF3 结构与坐标变换、每个组合自己的 top1、独立 WT 自身全长/删减结构及对应 docking pose |
| `data/preparation_inputs/` | 六组建膜输入、拓扑和力场依赖 |
| `data/preheat/<组合>/` | 六组实际采用的最小化分支、50 ps 升温和 75 ps 恒温结果、轨迹、结构、检查点及记录 |
| `data/production/<组合>/rep1/` | 两条生产的 NPT 准备、生产输入、轨迹、能量、日志和检查点快照 |
| `methods/` | 指向仓库现有方法说明、错误记录及相关代码的软链接 |
| `provenance/` | 必要来源与环境版本记录，不包含安装环境和下载缓存 |

六组为 N84V–ascr18、N84V–ascr3、V368R–ascr18、V368R–ascr3、独立 WT–ascr18、独立 WT–ascr3；目录标识与每组的真实来源见 [cases.json](cases.json)。独立 WT–ascr18 保留实际使用的 Trp174 侧链修复记录，它与此次弃用的共同骨架重建分支不同。

六组预热均保留完整的 0–125 ps 轨迹。两条生产仍未达到 100 ns；本次从 E2 按文件截取已有内容，回收时间为 **2026-10-05 10:12–10:17，北京时间**：

| 生产组合 | 本地保留轨迹末帧 |
|---|---:|
| N84V–ascr18 rep1 | 16.44 ns |
| V368R–ascr3 rep1 | 16.82 ns |

这是当前数据快照，不是 100 ns 完成归档，也不会自动跟随远端增长。E2 原运行目录仍是续跑来源；如需从本地恢复，须先核对检查点与输出匹配，不能假定逐文件截取的副本可直接追加续跑。原始配置内的 E2 路径作为发生记录保留，未改写成新的运行输入。

## 实体文件与软链接

DryLab 仓库或 Docking 项目中已有且内容相同的文件，只建立软链接；同一保留包中的重复内容也只存一份实体。临时目录或 E2 独有的数据才保存到本目录。没有软链接指向 `/private/tmp`，因此清理临时目录不会丢失这些保留文件。链接到 Docking 的原文件仍需保留在其原位置。

本次清单共 1,237 个文件入口：726 个独有实体、65 个指向仓库或 Docking 现有文件的链接、446 个包内复用链接，另有三处预热阶段的拓扑目录链接。新增实体数据约 **3.40 GB**。

文件来源、软链接目标和内容身份见 [manifest.json](manifest.json)。全部文件内容与来源一致；六组预热和两条生产快照都能读到各自末帧，详见 [validation.json](validation.json)。这些检查回答“文件是否保留下来”，不证明原始几何或偏好机制合理。
