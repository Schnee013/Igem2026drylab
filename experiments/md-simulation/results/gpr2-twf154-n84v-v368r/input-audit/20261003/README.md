### 候选生成前的连接点检查与方案

进一步在两份指定全长受体分别应用各自 `alignment.json`，使用相同的 N84V–ascr18 seed 和 V368R–ascr3 seed，核对 99、163、173、179 位连接区域。ascr18 seed 与 Cys173 主链 N 的距离，在 N84V 母体为约 0.806 Å，在 V368R 母体为约 0.857 Å；163/179 位并非这些最严重冲突的位置。该检查使用本目录 `audit_handoff.py` 的重原子读取和距离定义，输入身份由 `audit.json` 给出。

这意味着不能固定整个 Cys173、仅让它两侧的短环摆动。合理的局部搜索必须允许 Cys173 主链与侧链调整，同时以 Cys99–Cys173 连接的键长、键角和二面角约束维持二硫键相容几何。连接状态是来自预测模型的建模假设，仍需化学依据核查。

拟采用的算法类别为“内部扭转角采样＋闭环求解＋带约束全原子优化”：在给定全长母体上固定核心及 lid 两侧连接区域，采样 164–178 的主链 phi/psi、侧链旋转异构体和允许的二硫键扭转；同时要求 163→164、178→179 的肽链连接及 99↔173 交联闭合。可采用 GeneralizedKIC 等方法搭配交联约束实现，但普通两端 loop 闭合不能自动保证第三处交联正确，需针对本体系实现并验证联合/分步闭合。

先做小批候选验证闭合是否可行，再扩展采样、按几何与能量筛选并聚类。这里的“候选”只是同一输入受体的局部构象版本，不是新增受体模型来源。配体在候选生成期间固定使用指定 seed，不做重对接；筛选后约束释放的 MD 会允许正常运动。

## 机制分析建议

研究问题是为湿实验补充“偏好增强”的可检验机制解释；对接趋势是待检验机制假说。主分析应在每种配体内先比较 mutant 与 WT，再检查这种变化是否具有配体差异；只比较 N84V–ascr18 与 V368R–ascr3 会同时改变受体和配体。

- N84V：核查 84 周围的极性/疏水接触、水合与邻近残基网络是否改变，并连接到配体姿势/口袋几何。本次 N84V–ascr18 起点中 residue 84 与配体最近距离 6.124 Å，不能预设为直接抓住配体。
- V368R：检验胍基–羧酸相互作用、氢键、水介导联系及侧链重排，不预写“新增盐桥”的答案。本次 V368R 的 Arg368 胍基 N 到任一配体 O 的最小距离，ascr3 为 6.778 Å、ascr18 为 6.477 Å；起点未显示紧邻的直接盐桥几何。
- lid：跟踪 lid–口袋距离、lid–配体接触、局部构象与配体运动的关联；开口度定义和参考原子须在生产前确定。
- 可靠性：配体在受体参考系中的位移、分区接触占比/持续时间、分块时间序列、后续独立重复的一致性；不能比较两个不同大小配体的总接触数来直接推导亲和力。
- 复用现有七 driver 与已有共享分析能力。若水网络等指标确有缺口，先证明缺口再单独决定共享实现；本次未新增生产分析 driver。

两个优先 rep1 仅支持生成机制线索。对照和独立重复补齐前，不写成“已证明偏好性增强”；轨迹帧不是独立重复，单 rep 的时间块也不能代替 rep2/3。
