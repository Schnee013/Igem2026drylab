# P2 Economic Benefit Literature And Data Dossier

This folder is the durable source package for the P2 early-detection economic
benefit model. It promotes the useful synthesis outputs from the temporary
literature run while leaving raw API state, rejected pools, and checkpoint files
under `tmp_papers/`.

## Files

- `stage1-paper-data-matrix.md`: paper/data matrix, source quality tiers,
  model-ready parameter draft, and model-structure recommendation.
- `stage2-parameter-extraction.md`: extracted candidate parameters, scenario
  readiness, remaining gaps, and MVP/enhanced/Wiki model boundaries.
- `stage2-model-parameters.csv`: machine-readable candidate parameter table.
- `stage2-source-evidence.csv`: source provenance and extracted evidence table.

## Boundaries

- This package supports a framework-only economic model, not final ROI claims.
- The current public MVP examples are calibration scaffolds. They must be
  replaced with HP, wet-lab, and local market inputs before project-specific
  benefit claims.
- Docking Delta G, ODE Kd, and unverified wet-lab assumptions are not economic
  constants. They can only enter later as scenario or interface variables.
