# 文献管理使用说明
## 在哪里看文献
| 我想… | 去哪 |
|------|------|
| 快速查找某篇文献 | 本飞书多维表格（按 Tier 分组，支持搜索/筛选）文献矩阵视图 |
| 看某篇文献的详细总结 | 飞书云文档「iGEM 2026 文献查阅文档」 |

## 如何新增文献
1. 打开飞书多维表格
2. 在表格末尾新增一行，填写以下字段：
| 字段 | 必填 | 格式 | 示例 |
|------|------|------|------|
| **ID** | 是 | `第一作者姓+年份` | `Wang2025` |
| **Tier** | 是 | 从下拉选择 | `4a-GPR/Gpa1偶联改造` |
| **文献** | 是 | `作者 et al.` | `Wang et al.` |
| **期刊** | 是 | 期刊缩写 | `Nat Commun` |
| **年份** | 是 | 4 位数字 | `2025` |
| **核心内容** | 是 | 一句话摘要 | `新型 Gpa1 嵌合体提高 10 倍偶联效率` |
| **项目关联度** | 是 | 三选一 | `★★★` / `★★☆` / `★☆☆` |
| **DOI** | 建议填 | DOI 编号 | `10.1038/s41467-025-xxxxx` |
3. 用 AI 辅助阅读 PDF 并生成标准化输出（见下方「AI 辅助读文献」）
4. 将 AI 输出的**表格行**填入多维表格，**详细总结**追加到飞书云文档末尾
5. 在群里说一声 **"多维表格加了 xxx，ID 是 xxx"**
---
## ID 命名规则
- **基本格式**: `第一作者姓` + `年份` → `Hu2024`、`Shaw2019`
- **同姓同年**: 加小写字母后缀 → `Huang2023a`（Pathogens）、`Huang2023b`（Curr Biol）
- **同姓不同名**: 保留名字首字母 → `FanC2023`（Fan Cong）vs `Fan2024`（Fan Xiao）
- **iGEM 项目**: `iGEM-团队名+年份` → `iGEM-BITChina2017`
> **为什么不用序号？** 序号在插入新文献时会导致下游全部重编号，其他文档中引用的序号会失效。用 Author+Year 作为 ID 永远稳定。

## AI 辅助读文献
### 输入
给 AI 模型（Claude / ChatGPT / Kimi / DeepSeek 均可）提供：
1. **PDF 文件**（上传原文，不要只给摘要）
2. **下方 prompt**（直接复制粘贴）
### Prompt 模板
```
请阅读这篇论文，输出两部分内容。

## 第一部分：多维表格行

用竖线分隔，输出一行，字段顺序如下：
ID | Tier | 文献 | 期刊 | 年份 | 核心内容（一句话） | 项目关联度 | DOI

规则：
- ID = 第一作者姓 + 年份，如 Wang2025
- Tier 从以下选项中选一个最匹配的：
  1-NTF受体与信号通路 / 2-线虫ascaroside受体 / 3-Ascaroside生物学 /
  4a-GPR/Gpa1偶联改造 / 4b-下游通路改造 / 4c-显色输出 /
  5-iGEM历史项目 / 6-方法学
- 项目关联度：★★★（直接复现/必须引用）/ ★★☆（重要参考）/ ★☆☆（背景知识）

## 第二部分：详细总结

用以下固定格式输出：

## {ID} | {作者} ({年份}) {关联度}
**{论文完整标题}**
- **期刊**: {期刊名} {卷号}:{页码}
- **说明**: {3-5 句话概括核心发现，必须包含具体数据（EC50、倍数、p值等）}
- **项目关联**: {1-2 句话说明这篇文献对我们 iGEM 2026 项目的具体参考价值}
- **引用**: {作者缩写} ({年份}) *{期刊}* {卷}:{页}. DOI: {DOI}

注意：
- 「说明」只写论文原文内容，不要混入项目自身的实验数据
- 「项目关联」简要说明参考价值即可，具体对比分析由成员完成
- 所有数据必须来自原文，不确定的标注"原文未明确"
```
### 输出示例
AI 会返回类似这样的内容：
**第一部分（复制到多维表格）：**
```
Wang2025 | 4a-GPR/Gpa1偶联改造 | Wang et al. | ACS Synth Biol | 2025 | 新型 Gpa1-Gαi3 嵌合体将 GPCR 偶联效率提高 10 倍 | ★★☆ | 10.1021/acssynbio.xxxxx
```
**第二部分（追加到飞书云文档末尾）：**
```
## Wang2025 | Wang et al. (2025) ★★☆
**A novel chimeric Gpa1 strategy for enhanced GPCR coupling in yeast**
- **期刊**: *ACS Synthetic Biology* 14:123–135
- **说明**: 设计了 Gpa1 C-末端 12 aa 替换为 Gαi3 的新型嵌合体，在 SST2 受体偶联中 EC50 从 21 nM 降至 2.1 nM（~10 倍提升）。...
- **项目关联**: 嵌合 Gpa1 设计的新方案，C-末端替换长度介于 Brown2000 的 5 aa 和传统嵌合体的 142 aa 之间，可作为 GprC 偶联优化的候选策略。
- **引用**: Wang X et al. (2025) *ACS Synth Biol* 14:123–135. DOI: 10.1021/acssynbio.xxxxx
```
### 填写步骤
1. **多维表格**：把第一部分的竖线分隔内容，逐字段填入新行
2. **飞书云文档**：把第二部分整段追加到对应 Tier 章节的末尾
3. **群里通知**：`"加了 Wang2025，Tier 4a，嵌合 Gpa1 新策略"`
### 常见问题
**Q: 不确定该选哪个 Tier？**
A: 先选最接近的，在群里说明，dry lab 会调整。
**Q: 同姓同年怎么办？**
A: 先查多维表格有没有同 ID。有的话加后缀：`Huang2023a` 已存在 → 你的新文献用 `Huang2023c`。
**Q: AI 的总结靠谱吗？**
A: AI 总结大体可信，但具体数据（EC50、Kd、倍数等）**必须肉眼核对原文**。关键数据标错比没有更糟。

| Tier | 含义 |
|------|------|
| 1-NTF受体与信号通路 | GprC/Gpr2/Gpr3 受体鉴定、ascaroside 对接、NTF 信号通路 |
| 2-线虫ascaroside受体 | *C. elegans* 受体，嵌合设计的上游文献 |
| 3-Ascaroside生物学 | 化学、植物防御、跨界信号 |
| 4a-GPR/Gpa1偶联改造 | 酵母异源 GPCR 表达、嵌合 Gpa1 设计 |
| 4b-下游通路改造 | MAPK 通路调控、信号放大 |
| 4c-显色输出 | 番茄红素、紫色杆菌素等比色报告 |
| 5-iGEM历史项目 | 往届 iGEM GPCR/对接/传感器项目 |
| 6-方法学 | Vina、AlphaFold、IFP/ProLIF |

## 引用文献的正确方式
在 wiki、slides、其他文档中引用文献时，用 **ID** 而非序号：
```
✅ "GprC 的对接结果复现了 Hu2024 的 25 poses"
✅ "嵌合 Gpa1 设计参考 Brown2000 Table 3"
❌ "见文献 #1"（序号已废弃）
```
