SLIDE 2 | 模块 ① 分子对接 — 方法栈
==============================================================================

Pipeline:
  AF3 突变体结构预测 → ADFR 受体准备 → AutoDock Vina 单阶段对接
  → ProLIF IFP 交叉验证 → 双通道分级

对接参数 (与 Hu 2024 严格匹配):
  spacing = 0.1 Å
  exhaustiveness = 200
  box = 40 Å (TM 截断 + ICL3 移除, box center = TM helix 质心)
  seed = 42
  Gpr2 box 用 3D offset (修正胞内 pose 偏移, 见 SLURM job 6535: 76/80 EC)

双通道分类:
  sel_mut = ΔG(ascr18) - ΔG(ascr3)

  Channel A: sel < -0.477  →  ascr#18 偏好 (PPN 标志物传感器)
  Channel B: sel > +0.477  →  ascr#3 偏好  (背景参比传感器)

  阈值 0.477 = 3σ, σ = 0.159 kcal/mol (5-seed Gpr2_ascr18 重复方差实测数据)

WT 基线:
  GprC sel_wt = -0.798  (三受体最强天然 ascr#18 偏好)
  Gpr2 sel_wt = -0.404  (弱 ascr#18 偏好)
  Gpr3 sel_wt = +0.195  (弱 ascr#3 偏好)

SLIDE 4 | 模块 ① 关键洞察
==============================================================================

洞察 1: V138 同位点双通道开关 (Gpr3 TM4)
─────────────────────────────────────────────────────────────────────────────
  替换       sel_mut    通道       化学性质
  V138R      -0.875     A          大、带正电、胍基
  V138T      +1.042     B          小、极性、羟基
  V138L      +0.886     B          中、疏水
  V138K      ~0         neutral    与 Ala 等价
  V138H      ~0         neutral    与 Ala 等价

  V138R 是孤峰 (不是"碱性类别规律"),
  湿实验对照建议同时构建 V138R + V138K + V138H 三联

洞察 2: GprC 天然 ascr#18 偏好极强 + 当前不入 MD production 的原因
─────────────────────────────────────────────────────────────────────────────
  对接侧观察:
    GprC WT sel_wt = -0.798 (三受体最强)
    90 条 saturation 中仅 3 条翻转 Channel B (Q411S/L377S/R174N)
    其余 87 条只减弱偏好未反转
    → GprC 是天然 PPN 信号识别器, 工程化反转难度高

  Hu 2024 报告的 GprC 双定位性质 (与本项目 MD 决策相关):
    - GprC 是双功能 GPCR, 同时定位于细胞质膜 + 线粒体外膜
      (Mitotracker 共染 + 亚细胞分级 + 蛋白酶 K 处理验证)
    - 序列分析: GprC 第 82 位后含线粒体靶向信号 (MTS),
      预测线粒体定位概率 98.41% (vs GprD/E/F 仅 2.58/43.86/34.12%)
    - 双重信号通路:
      质膜路径   : GprC + GasA → ascaroside 信号 → 核内基因表达
      线粒体路径 : GprC + GasA → 激活线粒体呼吸 + ROS 产生
                   (ΔgprC 和 ΔgasA 中 ROS / OCR 均不增加)
    - 与人类 CB1 受体双定位类似; SRBC66 也预测 82.92% 线粒体共定位
      → 真菌 GPCR 双定位可能是 4 亿年趋同进化保守特征

  对项目的含义:
    - 我们的酵母传感器只复用 GprC 的质膜通路, 不需要线粒体功能
    - 但 GprC 在天然宿主中走 GasA → MAPK + 线粒体激活
      (与 Gpr2/3 的 cAMP-PKA 通路不同)
    - 嵌合 Gpa1 必须用 AfGasA 供体 (Group I Gα), 不能用 AoGpa2
    - GprC saturation Top Channel B 候选 (Q411S/L377S) 进入 §5 配对清单,
      可作为湿实验跨受体异构性配对验证 (Top 3: M327A + Q411S)

  GprC 当前不入 MD production 的三层原因 (按本质排序):
    1. 膜定位几何不确定性 (科学层, 主因):
       PPM 2.0 报 GprC 23.4 Å 薄膜 + 17° 倾斜 + 8 TM,
       显著偏离典型质膜 GPCR (Gpr2/Gpr3 PPM 报 30-33 Å, 倾斜 ≤6°, 7 TM)
       根因 = Hu 2024 报告的双定位特性:
         GprC 同时定位质膜 + 线粒体外膜
         线粒体外膜 ~25-30 Å, 几何匹配 PPM 报值
         → AF3 给的 GprC 结构可能不是质膜最优态,
           而是更接近线粒体外膜适配态或两态混合
       → 用 POPC 单纯质膜模拟 GprC 在科学解释力上有折扣
       注: 酵母异源表达无 fungal MTS 识别机制, 实际仍走质膜路径
            → 不是硬性阻塞, 但需提高对结果的解读门槛
    2. 嵌合配对独立通路 (优先级层):
       GprC × AfGasA 是 AF3 唯一展现 cognate 特异性的配对 (Δ=+0.16),
       与 Gpr2/3 × AoGpa2 主路线独立 (走 MAPK vs cAMP-PKA)
       → 优先验证双通道传感器 Channel A/B 主路线,
         GprC 作为补充验证
    3. 体系尺寸 (工程层):
       GprC X 轴跨度 97.9 Å > 标准 90 Å, 需 XY ≥ 130 Å box
       体系 ~300k atoms (vs core 200-250k), 3 reps 多耗 ~2 d wall time
       → Ch-3 (GprC + AfGasA-C25) 降为 stretch,
         等核心 12 traj 完成后 GPU 余量启动

洞察 3: F170 (Gpr3 ECL2) 酸碱双向
─────────────────────────────────────────────────────────────────────────────
  F170E / F170D       → Channel A (酸性增 ascr#18)
  F170K / F170N / F170H → Channel B (碱/极性增 ascr#3)
  机制不如 V138R 清晰

SLIDE 5 | 模块 ① 跨受体配对推荐
==============================================================================

双通道传感器 = 1 个 Channel A 突变体 × 1 个 Channel B 突变体

  #   Channel A          Channel B          D (判别力)   balance
  1   Gpr2-M327A         Gpr3-V138T         -2.433       0.572
  2   Gpr2-M327A         Gpr3-V138L         -2.277       0.611
  3   Gpr2-M327A         GprC-Q411S         -2.150       0.647
  4   Gpr2-M327D         Gpr3-V138T         -2.131       0.511
  5   Gpr2-M327A         Gpr3-V138P         -2.127       0.654

  D       = sel_A - sel_B          (越负 = 两通道分离越远)
  balance = |sel_A| / (|sel_A|+|sel_B|)  (越接近 0.5 越对称)

推荐策略 (湿实验取舍):
  最大判别力      → Top 1 (M327A + V138T)
  跨受体异构性    → Top 3 (M327A + Q411S, 验证 GprC 通道)
  对称灵敏度      → Best balance (Gpr2-R59E + Gpr3-F170N, balance = 0.500)
