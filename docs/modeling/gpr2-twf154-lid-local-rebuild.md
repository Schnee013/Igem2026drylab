# Gpr2：保留本组合 pose 的局部 lid 重建思路

本文是保留本组合受体和 pose 的局部重建方法记录。后续已完成 [两组各自来源的候选生成与静态检查](../../experiments/md-simulation/results/gpr2-twf154-n84v-v368r/lid-rebuild-own-pose-20261005/README.md)，正式验收与膜体系准备仍未完成；实际状态回该结果入口。用户同日后续选择 V368R–ascr3、独立 WT–ascr3 使用该类重构起点；当前输入与明确文件名见 [输入选择合同](../../experiments/md-simulation/results/gpr2-twf154-n84v-v368r/input-selection-20261005/README.md)。旧混杂重建版的停用范围和归档入口见 [本轮结果说明](../../experiments/md-simulation/results/gpr2-twf154-n84v-v368r/README.md)。

## 要解决的问题

对接阶段移除 lid、开放口袋搜索空间的动机与观察见[决策 006](../decisions/006-gpr2-twf154-docking-lid-deletion.md)。本方法承接选定姿态恢复到全长受体后的局部结构准备。

当一个确定组合的原始 docking pose 放回该组合自身的全长受体后，与 ECL2（164–178）发生不能接受的重叠或穿过盖子开口的几何关系时，可以尝试局部重建 ECL2。要改变的是盖子的构象，不能同时换受体母体、配体 pose 或突变侧链，随后把结果解释成盖子的作用。

## 保留什么，允许改变什么

每个组合独立从其指定全长受体和**该组合自己的 top1 pose**开始。N84V–ascr3 始终保留 N84V–ascr3 的 pose，V368R–ascr18 始终保留 V368R–ascr18 的 pose；其余组同理。

先恢复文件本来约定的共同坐标系：突变体 `af3_original/raw_model0.pdb` 是 AF3 原始坐标，`top1.sdf` 已处于 docking 坐标系，须按各自 `docking_receptor/alignment.json` 对**本组合整条全长受体**作已有刚体变换 `xyz_docking = xyz_AF3 @ R + t`；独立 WT 的 `full_length.pdb` 已在自己的 docking 坐标系。不能直接把突变体 raw PDB 与已对齐 SDF 拼在一起。此步骤恢复的是既有对接关系，不是换骨架或重新对接；坐标不变性以共同坐标系下的原始复合物为参考。此后受体与配体只接受一起进行的坐标系变换，不能单独挪配体来腾空间。当前两个合同已明确此规则；实际六组装配核查见 [输入审查](../../experiments/md-simulation/results/gpr2-twf154-n84v-v368r/input-selection-20261005/audit-20261005/README.md)。

候选生成期间，固定配体重原子和 ECL2 以外的受体原子，固定 163、179 两侧连接区域；只采样 164–178 的主链扭转角和侧链构象。保留本组合原来的 84、368 位侧链与其他环区，不从另一个突变体回变来代替它。若固定范围导致无解，应记录具体限制；不能默默扩大可动范围或换 pose。

当前体系采用的 Cys99–Cys173 二硫键仍是需保留的建模连接假设。Cys99 在固定区，Cys173 属于可动的 lid，不能把 Cys173 整个冻结而仍声称 lid 可自由挪开；需要同时维持二硫键相容的成键几何。

## 方法流程

1. **先判断需要改动的范围。** 逐原子定位冲突和穿越部位。如果只是一根侧链朝向问题，先尝试该 lid 侧链的旋转；主链确实横穿配体所在区域时才进入整段环重建。
2. **采样局部扭转角并求闭合。** 采样 lid 的主链 φ/ψ 与侧链 χ，通过 GeneralizedKIC 一类闭环求解，恢复 163→164、178→179 的肽链连接，并联合或分步满足 99↔173 的二硫键几何。Rosetta 的 [GeneralizedKIC 二硫键教程](https://docs.rosettacommons.org/demos/latest/tutorials/GeneralizedKIC/generalized_kinematic_closure_4)提供了交联闭合的方法基础，但本体系的两端加交联约束仍需单独验证。
3. **只优化盖子，保留多个不同候选。** 对候选进行局部全原子重排与带约束最小化；配体作为固定的空间障碍参与相容性检查。优先保留成键和主链构象合理、改动较小且不穿越配体的构象，再按构象聚类，而不是简单选择离配体最远者。蛋白建模能量不能当作配体亲和力分数。
4. **核对实际坐标变化。** 检查盖子以外和配体是否确实保持原坐标，检查肽链连续性、手性、二硫键、非键合接触和真实共价环的互锁；再查看 lid 与配体的三维空间关系。仅凭“没有很短的原子距离”不足以排除穿过开口。开放 ECL2 的人为补面交点也不能直接当作真实闭环互锁。
5. **必要时再进入膜内准备。** 对选定候选使用相同的力场与膜环境进行最小化、预热和逐步释放约束；与原始版比较时保留同一受体母体、同一 ligand pose 和一致的准备条件。需要重新计算的步骤不得拿旧版末态拼接代替。
6. **保留解释边界。** 候选只是一个几何上可容纳原 pose 的起点，不是盖子真实移开的动力学路径。释放约束后是否保持、闭回或出现其他状态，应由后续采样判断；找不到候选也只说明本次限定采样未找到解。

## 可沿用的经验与需要改正的部分

旧试验的 [sample_disulfide_lid.py](../../experiments/md-simulation/scripts/sample_disulfide_lid.py) 已实现局部扭转采样、闭环和带约束精修，可作为后续实现参考；其运行配置和后续矩阵生成采用了共同 N84V 母体及跨组合共享 pose，**不可直接沿用为新的输入配置**。

旧试验提示，无限制 Cartesian 精修可能产生肽键/成键几何问题，因此局部优化需要保留这些几何条件。最终只改 lid 的方案仍须从每一组自己的输入重新建立；选择合同中的候选生成/验收状态决定是否已有可用坐标，不能从本方法文档推断重建、预热或生产已执行。
