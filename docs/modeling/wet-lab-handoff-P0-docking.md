# 湿实验交接：受体突变候选位点

## 1. 摘要

计算预测了 **8 个强候选突变（Tier 1）+ 29 个中度候选（Tier 2）**，建议湿实验组优先构建 **6 个 Top 候选**（覆盖 2 个受体、2 种机制路径）：

| 优先级 | 突变 | 受体 | ΔΔG_sel | abs sel | 机制路径 |
|---|---|---|---|---|---|
| 🥇 P1 | **M327A** | Gpr2 | −0.99 | **−1.39** | 丢失 ascr3 专属相互作用 |
| 🥈 P2 | **V138R** ⭐ | Gpr3 | −1.07 | **−0.88** | 引入 Arg（盐桥假说，待 MD 实证） |
| 🥉 P3 | **M327D** | Gpr2 | −0.69 | **−1.09** | 引入 Asp 主动增强 ascr18 |
| P4 | **R59F** | Gpr2 | −0.55 | **−0.96** | R59A 的等效替代 |
| P5 | **F170E** | Gpr3 | −0.70 | **−0.50** | ECL2 酸性替换 |
| P6 | **I141A** | Gpr3 | −0.79 | **−0.59** | TM4 腔体缩小 |

**核心结论**：

1. **Gpr2 M327A 仍是最强信号**（abs sel −1.39），ascr18 亲和力几乎不变。
2. **Gpr3 V138R 是 04-11 最重磅新发现** —— 把 Gpr3 从无选择性翻转到 abs sel −0.88，但盐桥机制目前只有空间富集证据，**未实证**（待 MD 补证）。
3. **底盘锁定酵母 STE2 + 嵌合 Gpa1** → 表达体系与读出方式见 §7。

**方法**：AlphaFold 3 Server 预测突变体结构 → AutoDock Vina 单阶段对接（spacing=0.1 Å, exhaustiveness=200, box=40 Å, seed=42, Hu2024 参数） → ProLIF IFP 交叉验证 → Tier 1-4 分级。

**完整计算数据**：`experiments/docking-repro/mutagenesis/tier_recommendations_20260411.md`（122 条 = 32 alanine + 90 saturation）

## 2. 候选突变位点

### 评级标准

ΔΔG_sel = ΔΔG(ascr18) − ΔΔG(ascr3)。**负值 = 增强 ascr18 偏好**。

| Tier | ΔΔG_sel 范围 | 含义 |
|------|-------------|------|
| 1 | ≤ −0.48 kcal/mol | 强选择性增强（>3σ, σ=0.159） |
| 2 | −0.48 ~ −0.16 | 中度选择性增强（1~3σ） |

### P1（最高优先级）：Gpr2 M327A

| 指标 | 数值 |
|------|------|
| ΔΔG_sel | **−0.99 kcal/mol**（Tier 1 最强） |
| mutant ΔG(ascr18) | −6.74 kcal/mol（WT: −6.83, 几乎保留） |
| mutant ΔG(ascr3) | −5.35 kcal/mol（WT: −6.43, 大幅削弱） |
| ΔΔG(ascr18) | +0.09（微弱影响） |
| ΔΔG(ascr3) | +1.08（强烈削弱） |
| **abs sel** | **−1.39** |

**位置**：TM6 第一个残基（Met327），IFP 接触频率全场最高（51 次/18+16+17 across ascr18/3/7）。

**机制**：Met327 的侧链硫-甲基与 ascr#3 形成的疏水接触远强于与 ascr#18 的接触。丙氨酸替换后，ascr#3 失去关键结合面，ascr#18 几乎不受影响。mutant IFP 显示 M327 从 Top 残基消失，QLN139/SER135 接管。

### P2（最重磅新发现）：Gpr3 V138R ⭐

| 指标 | 数值 |
|------|------|
| ΔΔG_sel | **−1.07 kcal/mol** |
| mutant ΔG(ascr18) | −6.14（WT: −5.72，**比 WT 更强**） |
| mutant ΔG(ascr3) | −5.26（WT: −5.92，削弱 +0.66） |
| ΔΔG(ascr18) | −0.41（**主动增强**） |
| ΔΔG(ascr3) | +0.66 |
| **abs sel** | **−0.88** |

**位置**：TM4（Val138 → Arg138）。

**机制（待实证）**：V138 全 18 谱中 V138R 是**孤峰**——同位的 V138K/V138H 与 V138A 基线几乎等价，而 V138R 比第二名 V138Y 强 0.6 kcal/mol。Arg 胍基可能与 ascr18 末端羧酸形成静电互补 / 盐桥，但 mutant IFP 显示 ARG138 对 ascr18 接触 9 次 vs ascr3 仅 2 次，**这 9 次全部为 VdWContact**（本轮 ProLIF 未开启 Ionic 通道），目前只能证明"空间富集"而非"盐桥形成"。

**MD 实证已转交** [P0-md-simulation](P0-md-simulation.md)：测量 ARG138 胍基 Nε/NH₁/NH₂ 与 ascr18 羧基 O 的距离/角度时间序列 + 盐桥占比，WT 对照。

**湿实验注意**：Gpr3 整体亲和力比 Gpr2 弱，需注意表达水平和读出灵敏度；不要默认用 Lys 或 His 作为 Arg 的等价替代（V138K/V138H 在计算中无效）。

### P3：Gpr2 M327D — 引入羧基的激进路径

| 指标 | 数值 |
|------|------|
| ΔΔG_sel | **−0.69 kcal/mol** |
| mutant ΔG(ascr18) | −6.67 |
| mutant ΔG(ascr3) | −5.58 |
| ΔΔG(ascr18) | +0.17 |
| ΔΔG(ascr3) | +0.85 |
| **abs sel** | **−1.09** |

**位置**：同 M327A（TM6 第一个残基）。

**机制**：与 M327A 互补 —— Ala 是"删除策略"，Asp 是"主动引入策略"（羧基 + 极性）。mutant IFP 显示 VAL377 +13、ASN381 +11 新接触，ASP327 直接形成 HBond。

**适用场景**：若想在 M327 位点尝试**激进调节方向性**（而不仅仅"保亲和力"），用 M327D；若优先稳健，用 M327A。

### P4：Gpr2 R59F — R59A 的等效替代

| 指标 | 数值 |
|------|------|
| ΔΔG_sel | **−0.55 kcal/mol** |
| mutant ΔG(ascr18) | −6.66 |
| **abs sel** | **−0.96** |

**位置**：TM2（Arg59 → Phe59），IFP 45 次（WT，16/14/15）。

**机制**：R59F 与 R59A 几乎等效（abs sel −0.96 vs −0.92）。Phe 的芳香性不破坏选择性 → 说明 R59 的作用主要是"失去正电荷侧链"而非"替换成何种残基"。mutant IFP：**PHE59 本身 24 vs WT 19（+5）**，TYR58/SER57 出现新接触。

**适用场景**：作为 R59A 的备选，提供两种侧链化学（Ala vs Phe）的对照点。

### P5：Gpr3 F170E — ECL2 酸性替换

| 指标 | 数值 |
|------|------|
| ΔΔG_sel | **−0.70 kcal/mol** |
| mutant ΔG(ascr18) | −6.25 |
| mutant ΔG(ascr3) | −5.75 |
| ΔΔG(ascr18) | −0.53（增强） |
| ΔΔG(ascr3) | +0.17 |
| **abs sel** | **−0.50** |

**位置**：ECL2（TM4 与 TM5 之间的胞外环）。

**机制（反直觉，待 MD 实证）**：F170D/F170E 双双进 Tier 1，方向一致。但 mutant IFP 显示 **GLU170 与 ascr3 接触（23）反而比 ascr18（14）多** —— 整体 ΔG(ascr3) 仍上升 +0.17，说明"多接触 ≠ 更强亲和"，可能 GLU 引入诱导 ascr3 pose 偏移使其他关键残基失去接触。机制不如 V138R 清晰，待 MD 检查 pose drift 与 GLU170 侧链取向时间序列。

**设计启发**：F170→酸性 + V138→Arg 组合理论上可叠加，但**未在计算中验证双突变**，可作为湿实验探索方向。

### P6：Gpr3 I141A

| 指标 | 数值 |
|------|------|
| ΔΔG_sel | **−0.79 kcal/mol** |
| mutant ΔG(ascr18) | −5.19（亲和力偏弱） |
| mutant ΔG(ascr3) | −4.60 |
| ΔΔG(ascr18) | +0.53 |
| ΔΔG(ascr3) | +1.32 |
| **abs sel** | **−0.59** |

**位置**：TM4（Ile141）。

**机制**：双配体亲和力均下降，但 ascr#3 损失显著更大。可扭转 Gpr3 偏好方向。**注意**：Gpr3 整体亲和力偏弱（WT ΔG(ascr18)=−5.72），I141A 后 −5.19 进一步偏弱，实验信号可能弱于 Gpr2 突变体；表达系统需配合放大策略。

## 4. 实验建议

### 4.1 定点突变（Site-Directed Mutagenesis）

**优先构建顺序**（6 个 Top 候选，按信号强度 + 机制路径覆盖）：

1. **Gpr2 M327A** — 信号最强（abs sel −1.39），ascr18 亲和力保留最好
2. **Gpr3 V138R** ⭐ — 04-11 最重磅新发现，孤峰，需湿实验+MD 双重验证
3. **Gpr2 M327D** — 同位互补路径（引入羧基 vs 删除侧链）
4. **Gpr2 R59F** — R59A 的等效替代，提供两种侧链化学对照
5. **Gpr3 F170E** — ECL2 酸性替换，可与 V138R 构成 Gpr3 双突变设计探索
6. **Gpr3 I141A** — Gpr3 第二候选，注意亲和力偏弱

**密码子选择**（酵母 S. cerevisiae 偏好）：

| 突变 | 推荐密码子 |
|---|---|
| → Ala | GCT / GCC |
| → Asp | GAT / GAC |
| → Phe | TTT / TTC |
| → Arg | AGA（酵母最高频）/ CGT |
| → Glu | GAA / GAG |

建议使用标准 SDM（重叠延伸 PCR 或 Gibson Assembly）。底盘=酵母 + 基因组整合策略下，所有 6 个突变体应整合到同一位点（细节见 §7）。

### 4.2 功能验证

**推荐读出体系**：基于 STE2 通路的内源 MAPK 报告系统（pFUS1-报告基因，方案 TBD）；与外源 BRET 平台并行可作为交叉验证。

**实验设计**：

| 构建体 | ascr#18 剂量响应 | ascr#3 剂量响应 | 预期结果 |
|--------|-----------------|----------------|---------|
| WT Gpr2 | EC50 基线 | EC50 基线 | 两配体均有响应 |
| Gpr2 M327A | EC50 ≈ WT | EC50 右移 ≫ WT | ascr18 保留，ascr3 显著减弱 |
| Gpr2 M327D | EC50 ≈ WT 或左移 | EC50 右移 | ascr18 主动增强，ascr3 削弱 |
| Gpr2 R59F | EC50 轻微右移 | EC50 明显右移 | 与 R59A 等效（如有 R59A 数据） |
| WT Gpr3 | EC50 基线 | EC50 基线 | 略偏 ascr3 |
| Gpr3 V138R ⭐ | EC50 **左移** | EC50 右移 | 偏好翻转 + 主动增强 ascr18（盐桥假说预期） |
| Gpr3 F170E | EC50 左移 | EC50 ~ WT | ascr18 增强，ascr3 几乎不变 |
| Gpr3 I141A | EC50 右移 | EC50 大幅右移 | 偏好翻转为 ascr18 |

**配体浓度**：建议 10⁻⁹ ~ 10⁻⁴ M 梯度（8-10 个点），覆盖预期 EC50 范围。

**注意 V138R 验证策略**：建议至少同时构建 **V138R + V138K + V138H** 三个对照（其余两个在计算中无效），实测如果只有 V138R 显著则印证"Arg 胍基特异效应"；如果三者均强则推翻"孤峰"判断、回到"碱性类别规律"。

### 4.3 对照实验

| 对照 | Hu2024 角色 | 湿实验预期 |
|------|------|------|
| **WT 受体** | — | 正常响应基线 |
| **空载体** | — | 无响应（排除内源信号） |
| **GprC N60A** | **阳性对照**（N2.57A，已验证功能丧失） | ascr18 响应**削弱** |
| **GprC S44A** | **阳性对照**（S2.41A，已验证功能关键） | ascr18 响应**削弱** |
| **GprC N56A** | **阴性对照**（N2.53A，Hu2024 原文"无影响"） | ascr18 响应**保留** |

**Hu2024 对照的使用边界（2026-04-12 更新）**

这三个 Hu2024 对照用于**校准湿实验 assay 读出可信度**（阳性削弱 / 阴性保留的预期差异），**不作为我们 docking pipeline 的独立验证依据**。

我们的 docking 对 GprC 四个 Hu2024 对照的实际结果：

| 突变 | Hu2024 角色 | 我们 docking ΔΔG_sel | 我们 docking Tier |
|---|---|---|---|
| **N56A** | 阴性 | **+1.139** | Tier 4 |
| S44A | 阳性 | +1.032 | Tier 4 |
| N60A | 阳性 | +0.396 | Tier 4 |
| R395A | 阳性 | +0.370 | Tier 4 |

阴性对照 N56A 扰动**大于**所有三个阳性对照；GprC 14 个 alanine 扫描残基中 **13/14 落 Tier 4**（剩 1 个 ΔΔG_sel=+0.04 为 Tier 3 中性区）→ 当前 pipeline 在 GprC 上对单点 alanine 扰动不能可靠区分功能性 vs 非功能性残基。失败 root cause 未定，至少有两种不互斥解释：

- (a) **pipeline 普遍问题**：Vina 单点 alanine 扰动默认放大口袋破坏；
- (b) **GprC 口袋物理特异性**：口袋浅 / 接触残基密集，任何单点扰动都破坏结合（若此，落 Tier 4 是"真阳性 + 缺乏分辨力"而非"假阳性"）。

区分这两种情形需对比 Gpr2/Gpr3 阴性对照的扰动分布或重做 GprC box/seed 控制实验，**本次交接不阻塞**（详见 §5 新增条目）。

**湿实验角度的含义**：

- 如果湿实验看到 N56A 保留响应 + N60A/S44A 削弱响应 → 湿实验 assay 分辨率优于 GprC docking，是**预期结果**；
- 如果湿实验看到 N56A 也显著削弱 → 说明湿实验 assay 有普遍假阳性，需排查；
- Top 6 候选**全部来自 Gpr2/Gpr3**，不涉及 GprC，不受此分辨率问题影响。

> **BW→序列号映射可信度（2026-04-12 追溯完成）**：N56↔N2.53 / N60↔N2.57 / S44↔S2.41 的映射经 D2.50=ASP53 锚点 + DeepTMHMM TM2 范围（pos 45–65）+ Hu2024 三 strain 命名一致性三重验证（随机 match 概率 ≈ 1.25×10⁻⁴），可信度 HIGH。追溯记录见 [`docs/logs/truth-audits/2026-04-12_0205.md`](../logs/truth-audits/2026-04-12_0205.md) 后记 A。R395 的 R6.45/R6.55 BW 标签争议（[04-09 日志 §2](../logs/2026-04-09.md)）与本节角色分配解耦，不影响本交接。

## 5. 计算局限性

| 局限性 | 影响 | 缓解措施 |
|--------|------|---------|
| **单 seed Vina** | 噪声 SD=0.159 kcal/mol；ΔΔG_sel < 0.48 不可信 | Tier 划分以 3σ 为阈值；Tier 1 均 > 3σ |
| **刚性受体** | 构象选择限于 AF3 单预测 | 单点突变对骨架影响通常 < 0.1 Å RMSD |
| **AF3 预测精度** | pLDDT > 90 区域可信，loop 区不确定 | 仅在 TM helix 域内对接 |
| **Vina 评分精度** | 绝对 ΔG 误差 ±1 kcal/mol | 仅用**排名**，不用绝对值做决策 |
| ~~alanine-only~~ | ~~04-10 之前局限~~ | **2026-04-11 解除**：5 位点 × 18 AA 全谱完成（90 突变） |
| 静态对接无法直接证明动态相互作用类型（盐桥） | V138R 仅有空间富集证据 | 转交 [P0-md-simulation](P0-md-simulation.md) 做 MD 时间序列实证 |
| **GprC 单点扰动 pipeline 分辨率**（2026-04-12 发现） | Hu2024 阴性对照 N56A (ΔΔG_sel=+1.139) 扰动**大于**所有阳性对照（S44A +1.032 / N60A +0.396 / R395A +0.370）；GprC 14 个 alanine 残基 **13/14 落 Tier 4**（剩 1 个 ΔΔG_sel=+0.04 Tier 3 中性区）→ 当前 pipeline 在 GprC 上对单点 alanine 扰动无分辨力。Root cause 未定：(a) pipeline 普遍问题 vs (b) GprC 口袋几何特异，证据不足以区分 | **Top 6 候选全部来自 Gpr2/Gpr3**，不涉及 GprC；Gpr2/Gpr3 的 3σ=0.48 阈值来自 5-seed 方差内部自洽（SD=0.159），但**缺乏独立 in silico 阳/阴性对照背书** → 湿实验是最终确认环节 |

**重要提醒**：所有 ΔΔG_sel 数值仅反映**相对排名趋势**，不是热力学精确值。实验验证是确认效果的唯一途径。**特别是考虑到 GprC pipeline 分辨率问题（见上表末行），Top 6 的最终可信度取决于湿实验 EC50 对比，不取决于 Hu2024 in silico 对照。**

> **3σ=0.48 阈值来源说明（2026-04-12 补注）**：σ=0.159 kcal/mol 来自 Gpr2_ascr18 体系的 5-seed 重复方差评估（内部自洽噪声），**不是**从独立阴性对照群体标定出来的。配合 GprC 单点扰动分辨率问题（§5 末行），Tier 1 的 3σ 阈值是"超过本体系噪声"的必要条件，但不是"与背景扰动显著不同"的充分条件。Top 6 最终可信度仍需湿实验 EC50 对比。

### 三大新发现（vs 04-10 alanine-only 版）

1. **Gpr3 V138R 最重磅**：从无选择性翻转到 abs sel −0.88，机制方向与盐桥一致但**未实证**（待 MD）。
2. **Gpr3 F170 酸性规则**：F170E + F170D 双双进 Tier 1，方向一致；F170 位于 ECL2，可能是入口路径效应。
3. **Gpr2 M327 双路径**：M327A（删除）vs M327D（引入羧基）互补，覆盖两种工程化策略。

### Tier 2 摘要（29 个，详见 JSON）

- **Gpr2**：M327F、R59E（abs sel ≤ −0.62 的 2 个）
- **Gpr3 V138 系**：V138Y/N/S/I/H/K/A 等共 8 个进 Tier 2（V138 是 Gpr3 的"开关位"）
- **Gpr3 F170 系**：F170C/V/A/G/L/R/I/S/Y 等
- **Gpr3 I141 系**：I141E/S/P/T/C/N/Y/R/M/H 等

### 教训：孤峰 vs 类别规律

V138R 是孤峰（同位 V138K/V138H 与 Ala 基线等价），**不是"碱性残基类别规律"**。湿实验设计不能默认 K/H 作为 R 的等价替代。该教训写入 memory（feedback_outlier_vs_rule.md）。

### EC50 解读注意

由于**基因组单拷贝**而非高拷贝质粒：

- 受体表达水平较低，EC50 绝对值可能比文献酵母 GPCR biosensor 的多拷贝数据高 1-2 个数量级
- 但**突变体之间的相对 EC50 比较**（M327A vs WT 等）不受影响 —— 这是本干实验的核心读出
- 不要把 EC50 绝对值与 Hu2024 / Kuo2024 的真菌原生体系直接对比；体系不同

### 6 个候选的构建建议

为保持可比性，建议：

1. 所有 6 个突变体使用**同一表达盒**（同启动子、同信号肽、同 tag、同整合位点、同嵌合 Gpa1 版本）
2. WT Gpr2 + WT Gpr3 各做一个独立菌株作为基线
3. 至少为 V138R 加做 V138K + V138H 对照（验证孤峰假说）
4. Hu2024 对照（GprC N60A / S44A 阳性 + N56A 阴性）用于**校准湿实验 assay 读出可信度**（预期阳性削弱 / 阴性保留），而**不是**用作我们 docking pipeline 的独立验证依据 —— 我们 docking 对这四个 GprC 对照的实际分辨率问题见 §4.3 + §5 末行
