# 本轮 lid 重建输入混杂：保留的错误记录

2026-10-05，用户明确要求：移动某组合的 lid 时，保留该组合自己的全长受体与配体 pose。旧方案将“共同 N84V 母体＋同配体共享 pose”的重建分支与“各自 AF3 受体＋各自 docking pose”的原始分支并列，导致部分配对除了 lid 还改变了配体起点、其他骨架或突变侧链。不能把两版之间的差异归因于 lid 重建。

六套旧重建版退出本轮比较与长期保留包；四套 N84V 骨架回变 WT 也按用户最新决定不纳入。原始四个突变组合和独立 WT 两组仍保留其实际输入及预热结果。旧 WT–ascr18 的 200 ns 项目不属于此次整理范围，原位置不变。

后续如确需重建 lid，遵循 [局部重建思路](gpr2-twf154-lid-local-rebuild.md)：固定本组合的 pose 和 lid 外坐标，仅在 lid 中采样、闭合与优化。旧代码可供参考，旧共享 pose 配置不沿用。本次没有重新建模或启动新计算。

保留原始版数据不代表所有起点都科学合理；已发现的冲突或穿过开口问题仍需独立解释。最小化/预热完成、原子不碰撞、真正闭环是否互锁、是否达到平衡是不同问题，不能互相代替。
