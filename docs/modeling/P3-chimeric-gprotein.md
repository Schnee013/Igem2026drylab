# P3: 嵌合 G 蛋白 (Gpa1) 设计的同源性建模

> 来源: PRD v3 §3.6 | iGEM 评审定位: 加分项
>
> **条件性方向**: 仅在底盘选**酵母**时优先级升至 P0（因为嵌合 Gpa1 是酵母方案的成败关键之一）。详见 [底盘决策](../prd/chassis-decision.md)。

## 解决什么问题

需要将 *A. oligospora* 的 Gα 蛋白 C 端嫁接到酵母 Gpa1 上，以实现信号传导兼容。C 端替换多少残基？如何保证折叠正确？

## 方法路线

1. 多序列比对 (MUSCLE/Clustal): 酵母 Gpa1 vs 真菌 Gα 蛋白
2. 同源性分析: 确定 C 端替换区域
3. AlphaFold-Multimer 预测嵌合蛋白结构
4. 稳定性评估

## 产出定义

- [ ] 嵌合方案建议（替换区域和残基数）
- [ ] 结构稳定性预测
- [ ] 嵌合蛋白 vs 原生蛋白的结构比较
