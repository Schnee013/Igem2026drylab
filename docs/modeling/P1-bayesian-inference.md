# P1: 标志物浓度 → 线虫丰度贝叶斯推断模型

> 来源: PRD v3 §3.4 | iGEM 评审定位: 增强叙事完整性

## 解决什么问题

给定检测信号强度，线虫种群密度处于什么范围的概率是多少？这是 PRD 原方向 A 的改进版——不追求精确的"浓度→丰度"映射（缺乏数据），改为贝叶斯推断框架，输出带置信区间的估计。

## 方法路线

1. 建立参数化的正向模型: 线虫数量 → 分泌速率 → 土壤浓度 → 传感器响应
2. 以分泌速率为不确定参数，设置合理的先验分布
3. 用贝叶斯推断从传感器信号反推线虫密度的后验分布
4. 输出带置信区间的丰度估计

## 工具栈

| 参数 | 来源 | 不确定性 |
