### [4] 错误指针 — KNOW-1 §6 列标签与数值不匹配（跨文件数据矛盾）

> KNOW-1 §6 表格列标题为 `ΔΔG_sel`，V138R 显示 −0.88，M327A 显示 −1.39

- **问题**：这些数值实际是 **abs sel**（mutant 绝对选择性），不是 ΔΔG_sel（相对 WT 的选择性变化）。权威源 `tier_recommendations_20260411.md:26` 明确区分两列：V138R ΔΔG_sel = −1.070，abs sel = −0.88。同时 KNOW-3 §1:37 和 DO-2:19 正确使用 ΔΔG_sel = −1.070。
- **证据**：
  - `tier_recommendations_20260411.md:26`：列标题 `ΔΔG_sel | **abs sel**`，V138R 分别为 −1.070 | −0.88
  - `know-1-what-we-computed.md:128-133`：列标题 `ΔΔG_sel`，V138R = −0.88（实为 abs sel）
  - `know-3-honest-boundaries.md:37`：ΔΔG_sel = −1.07（正确）
  - `do-2-mutant-workflow.md:170`：ΔΔG_sel = −1.070（正确）
- **应该怎么说**：列标题改为 `abs sel`，或数值改为真正的 ΔΔG_sel（−0.987 / −1.070 等）。同时排序描述"按 |ΔΔG_sel| 排序"与实际排序（按 |abs sel|）不符
- **严重度**：**HIGH** — 学生在 DO-2 手算 ΔΔG_sel ≈ −1.08，但 KNOW-1 表格说 −0.88，直接矛盾。KNOW-1 是学生最先读的参考表，错误传播面最大
- **注**：此错误在上一 session 创建 KNOW-1 时引入，本 session 未修改该文件内容，但本 session 的映射工作将 qa-bank 指向了此错误表格

### 建议行为修正

1. **§号映射必须 Read 目标 section 内容验证**：仅凭 section 标题映射会导致错误。映射前必须 Read 目标 section（至少前 5 行）确认内容与 source 匹配。
   - **Why**：本次 4 条 MEDIUM 映射错误（Q2/Q3/Q11/Q29）全因仅 grep 标题未 Read 内容
   - **How to apply**：任何 `§N` 指针写入文档前，先 Read 对应文件的 §N 段落确认内容匹配

2. **跨文件同一指标须 Grep 全局一致性**：创建教学文档后应 Grep 同一指标名（如 ΔΔG_sel）在所有 v2 文件中的数值，检查一致性。
   - **Why**：KNOW-1 §6 把 abs sel 标记为 ΔΔG_sel，与 KNOW-3/DO-2 矛盾，HIGH 级错误
   - **How to apply**：创建含数值表格的文档后，对关键指标做 `Grep pattern path/` 一致性扫描

3. **风险识别 → 缓解行动不可脱节**：如果自己识别了"X 风险存在"，必须在继续执行前采取至少一个验证步骤，不能只在回复中提醒用户
   - **Why**：compaction 评估中正确识别了映射风险，但随后直接执行了映射而没有先验证
   - **How to apply**：自评中每一条 risk 必须跟一条 mitigate action，在同一轮完成
