## §3 第一性原理审查 + 修复

### CRITICAL：generate_mutant_fastas.py 用了 TM-only PDB 而非全长

**逻辑**：Hu2024 提交全长序列给 AF2 web server → 预测全长结构 → 提取 TM 域。AF2 的 MSA/结构预测依赖全长序列上下文，截断 TM 域会改变预测结果。

**修复**：`generate_mutant_fastas.py` 改为读取全长 PDB（`experiments/docking/receptors/{rec}_*.pdb`），不再读取 TM PDB。

### HIGH：config.yaml ascr1 SMILES 和分子式错误

SDF 文件实际为 C13H24O6（C7 链长饱和 ascaroside），之前错误写为 C9H16O5。已修正 SMILES 和 formula。

## §5 AF2 → AF3 方法差异

### 问题

Hu2024 使用 AlphaFold **2** web server 预测突变体结构（参数：5 models, 24 max_recycles, 2 num_ensemble）。当前 alphafoldserver.com 运行的是 AlphaFold **3**（diffusion-based 架构），不提供 max_recycles / num_ensemble 参数。

### 影响

- AF3 与 AF2 的结构预测架构完全不同，预测结果会有差异
- 无法精确复现 Hu2024 的突变体建模步骤
- 但 AF3 整体预测质量通常优于 AF2

### 决策

暂用 AF3 继续推进（当前唯一免费可用的 web server），观察突变体对接结果。如果阳性对照（N83A/R281A/S77A）复现失败且怀疑是结构预测差异导致，再考虑 ColabFold（AF2）或本地部署 AF2 作为替代方案。
