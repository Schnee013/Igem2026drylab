## §5 AF2 → AF3 方法差异

### 问题

Hu2024 使用 AlphaFold **2** web server 预测突变体结构（参数：5 models, 24 max_recycles, 2 num_ensemble）。当前 alphafoldserver.com 运行的是 AlphaFold **3**（diffusion-based 架构），不提供 max_recycles / num_ensemble 参数。

### 影响

- AF3 与 AF2 的结构预测架构完全不同，预测结果会有差异
- 无法精确复现 Hu2024 的突变体建模步骤
- 但 AF3 整体预测质量通常优于 AF2

### 决策

暂用 AF3 继续推进（当前唯一免费可用的 web server），观察突变体对接结果。如果阳性对照（N83A/R281A/S77A）复现失败且怀疑是结构预测差异导致，再考虑 ColabFold（AF2）或本地部署 AF2 作为替代方案。

## §9 GprC 偏差根因确认（04:00–04:30）

### Hu2024 原文方法确认

读 Hu2024 原文 PDF（p.1760-1761 "Modelling and docking"）：
- **pLDDT > 0.85 是质量描述**，不是 TM 提取阈值。原文："They showed high pLDDT scores (>0.85) for the TM helices, which in principle allows docking studies"
- **TM 拓扑用 Phyre2 + TMHMM 2.0 预测**（p.1760 Plasmid construction）
- 我们的 pLDDT 自动提取方法从一开始就与 Hu2024 不同

### UniProt + DeepTMHMM 交叉验证

三个受体均为 7-TM GPCR，都有大型 ICL3（胞内环 3）：

| 受体 | TM1-5 | ICL3 | TM6-7 | ICL3 长度 |
|------|-------|------|-------|---------|
| GprC | 15-192 | 193-373 | 374-427 | **180 aa** |
| Gpr2 | 30-206 | 207-326 | 327-377 | 119 aa |
| Gpr3 | 17-196 | 197-294 | 295-342 | 97 aa |

UniProt 注释链接：[A0A437AGY2](https://www.uniprot.org/uniprotkb/A0A437AGY2)、[G1X9E2](https://www.uniprot.org/uniprotkb/G1X9E2)、[G1XJN1](https://www.uniprot.org/uniprotkb/G1XJN1)
DeepTMHMM 结果：`experiments/docking-repro/analysis/deeptmhmm/TMRs.gff3`

### 根因：ICL3 导致 grid box 偏移

质心分析证明 GprC 的 ECL（胞外侧真实结合位点）**完全在 40Å grid box 外面**：
- Grid center → ECL 距离: 36.4 Å
- ECL 到 grid center 各轴: x=26.8Å, z=22.3Å（均超 20Å 半径）
- ICL3 的 181 aa 质量把质心拉向胞内方向
- Vina 在 box 内搜索只能找到 ICL3 区域的非生理性结合位点

**这是 GprC ΔG 偏差 2-3 kcal/mol 的确凿根因。**

### 修复计划

详见 `~/.claude/plans/witty-imagining-flamingo.md`
- 方案 A（推荐）：截断 ICL3 + 用 TM 螺旋质心定位 grid box
- 在 config.yaml 中定义 UniProt/DeepTMHMM 交叉验证的 7-TM 注释
- 重新提取 TM 域 → ADFR 准备 → 重跑 WT + alanine scan
