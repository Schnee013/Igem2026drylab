- User raised a first-principles question: whether the AF3-derived GPCR-Galpha/chimeric Gpa1 system could be screened by a shorter whole-system run and then replaced by local pocket/interface-only MD.

- Local pocket/interface-only MD is not accepted as an equivalent replacement for the unified full-system rerun. It can only be proposed later as supporting mechanism/refinement analysis with separate provenance and interpretation.
