# 2026-06-27

## E2 chctrl rep1 Slurm 同款分项分析重跑

### 目的

按用户要求，对 E2 产出的 `chimeric-ste2-gpa1-wt` / `chctrl` rep1 early-gate 数据运行与旧 Slurm chctrl Phase C5 相同的七个分项分析 driver。边界必须保持清楚：旧 Slurm 路线是 chctrl 3 reps 历史完成证据；E2 路线本次只分析 `rep1` early-gate snapshot，不是 E2 3 reps，也不是 final 500 ns production gate。

### 输入与配置

- E2 snapshot 根目录：`experiments/md-simulation/results/chimeric-ste2-gpa1-wt/early_gate/20260602_chctrl_rep1_early_gate/`
- 处理后轨迹：`processed/rep1/protein_ref.pdb` + `processed/rep1/prod_protein.xtc`
- gate-local config：`chimeric_systems.early_gate.json`
- config selection：`segid A` = `Gpa1-WT`，`segid B` = `Ste2`
- 复用旧 Slurm chctrl 分项 driver：`experiments/md-simulation/analysis/chctrl/analyze_convergence.py`、`analyze_alpha5_irmsd.py`、`analyze_hbond.py`、`analyze_com_distance.py`、`analyze_rmsf.py`、`analyze_bsa.py`、`analyze_contacts.py`
- 运行环境：`conda run -n chimeric-md-2025`

### 执行命令

```bash
set -euo pipefail
mkdir -p /private/tmp/drylab-mpl-cache
LOGDIR="experiments/md-simulation/results/chimeric-ste2-gpa1-wt/early_gate/20260602_chctrl_rep1_early_gate/analysis/run_logs"
export CHIMERIC_MD_CONFIG="experiments/md-simulation/results/chimeric-ste2-gpa1-wt/early_gate/20260602_chctrl_rep1_early_gate/chimeric_systems.early_gate.json"
export CHIMERIC_MD_REPS=1
export MPLCONFIGDIR=/private/tmp/drylab-mpl-cache
for script in \
  experiments/md-simulation/analysis/chctrl/analyze_convergence.py \
  experiments/md-simulation/analysis/chctrl/analyze_alpha5_irmsd.py \
  experiments/md-simulation/analysis/chctrl/analyze_hbond.py \
  experiments/md-simulation/analysis/chctrl/analyze_com_distance.py \
  experiments/md-simulation/analysis/chctrl/analyze_rmsf.py \
  experiments/md-simulation/analysis/chctrl/analyze_bsa.py \
  experiments/md-simulation/analysis/chctrl/analyze_contacts.py
do
  name="$(basename "$script" .py)"
  conda run -n chimeric-md-2025 python "$script" > "$LOGDIR/${name}.log" 2>&1
done
```

### 指标快照

- Convergence：rep1 final100/after100 RMSD slope = `0.004762 A/ns`；after100 mean RMSD = `7.98 A`。
- Alpha5 iRMSD：after100 mean = `2.72 A`，max = `4.26 A`；按项目 operational `<3 A` band 为 PASS-like。
- H-bond：top pair occupancy = `0.608`；`>0.10` 只作为项目 reporting heuristic，几何定义为 MDAnalysis-style `3.0 A / 150 deg`。
- COM distance：`ste2_cluster_A_222_251` after100 slope = `-0.0006858 A/ns`，mean = `15.56 A`；`ste2_cluster_B_288_304` after100 slope = `0.00247 A/ns`，mean = `11.50 A`。
- RMSF：baseline 已生成；本 control 系统没有 chimeric junction threshold。
- BSA：after100 mean fraction = `1.077`，min fraction = `0.947`；支持 retention under project operational `>=0.80` heuristic。
- Contact persistence：initial residue contacts = `34`；after100 mean retained = `0.631`，min = `0.412`；mean 支持 majority-retention heuristic `>0.50`，但 minimum 有低谷，解释时保留 caveat。

### 未包含项与边界

- 旧 Slurm Phase C5 summary 说明 MM-PBSA 未运行，因为 Slurm dependency check 中 `gmx_MMPBSA` 不可用，且当时不是 go/no-go evidence layer 的必需项；本次 E2 rep1 等价重跑也未补 MM-PBSA。
- `audit_selections.py` 是后续 selection audit diagnostic，不属于七个分项 driver；脚本正文多处硬编码旧 Slurm processed segid `PROA/PROB`，而 E2 early-gate config 使用 `A/B`。本次未直接运行该审计，避免生成错误链选择证据。
- 本次结果只说明 E2 `rep1` early-gate snapshot 在相同分项分析框架下产出了可读指标；不能替代 Slurm 3 reps 统计，也不能作为 E2 final production completion gate。
