> Scope: current source pointers in `experiments/md-simulation/systems/gpr2-R59C-ascr18/PACKAGE_STATUS.md`, their parent directories, and the five sibling `ifp_analysis*` result trees containing or producing ligand-pose material.

## Findings

### [7, 8] Missing path boundary and stale current source role

**File**: `experiments/md-simulation/systems/gpr2-R59C-ascr18/PACKAGE_STATUS.md`

**Issue**: the current MD package consumed a 20-pose SDF from an ignored IFP `tmp/` directory even though only the first pose is selected.

**Evidence**: the old source was `experiments/docking-repro/results/ifp_analysis_mutants_gpr3_f_full_20260520_0854/tmp/Gpr2_R59C_ascr18_poses.sdf`; it contains 20 SDF records, is ignored by `.gitignore` through `experiments/docking-repro/results/`, and had active references from `PACKAGE_STATUS.md` and `source_files.sha256`. Its first record is model 1 with 26 atoms, 26 bonds, and `VINA RESULT=-5.698`.

**Fix**: promoted the exact first SDF record to `experiments/md-simulation/systems/gpr2-R59C-ascr18/ligand/Gpr2_R59C_ascr18_pose1.sdf`; added a package-local manifest and replaced all current source/checksum pointers. The original IFP body is no longer a current MD authority.

**Status**: [FIXED]

**Severity**: HIGH

### [4, 6] Partially overlapping IFP result-directory names

**File**: `experiments/docking-repro/results/ifp_analysis_mutants_gpr3_f_full_20260520_0854/`

**Issue**: five top-level `ifp_analysis*` trees encode baseline, Gpr3-F rerun, mutant baseline, mutant Gpr3-F rerun, and the 2026-05-20 refreshed selection through suffix accumulation. The `gpr3_f_full` label is misleading because the refreshed set contains Gpr2, Gpr3, and GprC mutants.

**Evidence**: the three mutant contact tables contain 12, 10, and 16 unique receptor/mutation/ligand combinations. The sets partially overlap (`Gpr2/R59F` and `Gpr3/V138M`) but neither rerun is a strict superset of the others; direct CSV or directory merging would erase run-selection provenance. The trees are ignored generated outputs, while current source code and historical logs still encode their run-specific paths.

**Fix**: removed the refreshed tree from the current MD input chain by promoting the selected pose into the system package. No result tables were merged or renamed because their datasets are distinct historical run snapshots, not duplicate canonical inputs.

**Status**: [WONTFIX: preserve distinct historical run boundaries; no current MD consumer remains]

**Severity**: MEDIUM

### [4] Parent-directory role review

**File**: `experiments/md-simulation/systems/gpr2-R59C-ascr18/PACKAGE_STATUS.md`

**Issue**: verify that the remaining current pointers do not collapse reusable parameters, operation payloads, and manual handoff contracts into overlapping package directories.

**Evidence**: receptor AF3 files remain upstream provenance under `mutagenesis/af3_downloads/gpr2_r59c`; reusable ASCR18 parameter sources remain under `parameters/ascr18/deprotonated/...`; package-local topology inputs remain under `gromacs/`; receptor processing and PPM provenance remain under `receptor/`; the accepted manual upload body and settings remain under `receptor/charmm_gui_submission/`. PPM raw/clean output bodies are operation payloads, while the accepted upload PDB is the tracked handoff contract.

**Fix**: added the missing non-overlapping `ligand/` layer for the selected coordinate. No other current parent directory required a move.

**Status**: [FIXED]

**Severity**: MEDIUM
