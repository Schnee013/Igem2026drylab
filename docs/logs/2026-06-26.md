# 2026-06-26

## MD 算力优先级决策

### 背景

用户校准：chimeric Gpa1 control/chctrl 组 3 reps MD 完成发生在旧 Slurm 路线；E2 路线只有 chctrl rep1 及其 smoke / benchmark / early-gate 证据，不能写成 E2 完成 3 reps。当前能稳定使用的算力主要是 E2 共享服务器；此前 chimeric MD 几乎占满 A100，导致其他用户无法使用，因此后续必须先减少算力占用。

这里的“control/chctrl 组 3 reps MD 完成”只记录为旧 Slurm 历史进度事实；E2 仅记录 chctrl rep1 证据。任何稳定性结论、通过/失败判断、数值阈值或科学解释仍需回源到 GROMACS logs、trajectories、checksums、analysis outputs 和对应审查日志。

### 决策

1. 暂停 chimeric Gpa1 候选体系的大体系 full-production MD，不继续按旧 E2 unified rerun 路线直接推进 Ch-1/Ch-2/Ch-4。
2. chimeric Gpa1 线先调研省算力方案：
   - 尝试减少体系大小，只保留回答 receptor-Gpa1 interface 稳定性所需的必要原子、膜/水/离子范围；
   - 或加入更强物理限制、分层 restraint、局部区域约束等算法。
3. 在 chimeric 体系优化方案调研期间，先启动突变 GPR MD 的前置工作，从 current refreshed docking handoff 中 Channel A/B 的最佳推荐位点开始：
   - Channel A: `Gpr2_R59C`
   - Channel B: `Gpr3_R167Y`
4. 突变 GPR MD 第一阶段只做体系大小核查、资源估算和短程算力测试；不直接启动 full production。
5. E2 后续 MD 操作必须遵守共享服务器资源边界：不长期独占 A100，不启动未经确认的长程并发任务，测试命令需记录线程、GPU 占用、运行目录和日志路径。
