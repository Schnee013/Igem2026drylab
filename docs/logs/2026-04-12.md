| 层 | 选择 | 关键理由 |

| MD 引擎 | **GROMACS**（+ OpenMM 原型） | GPCR MD 文献 ~57%；iGEM 团队压倒性主流；LGPL 开源 |

## §4 后 4 维度深度调研（第二轮，已完成）

- 工具：`everything-claude-code:deep-research` + 3 并行研究子代理（WebSearch + WebFetch）

- 产出：[P0-md-tech-stack-research.md v2.0 §6-10](../modeling/P0-md-tech-stack-research.md)

- [x] **时间尺度惯例（§6）**：GPCRmd-2 协议 3×500 ns 固化为 class A 标准；200 ns × 3 rep 是 "可审稿地板"，500 ns × 3 rep 是 "舒服中位数"。A100 80GB 在 80k-atom 膜体系 265.8 ns/day（[NHR@FAU 2024](https://hpc.fau.de/2024/08/13/gromacs-2024-1-on-brand-new-gpgpus/)），本项目 ~120k 原子 ≈ 175 ns/day。**MVP 决策 = 7 holo × 200 ns × 3 rep = 4200 ns ≈ 24 GPU-day**
- [x] **分析工具（§7）**：主栈 **MDAnalysis + ProLIF + pandas**；ProLIF `Cationic/Anionic` 类**已原生覆盖**动态盐桥指纹（现有 `run_ifp_mutants.py` 可直接迁移到 trajectory）；`itertools.groupby` 做 contact lifetime run-length encoding；**GetContacts 作 GPCR 社区 cross-check**（4.0 Å 判据）。F170E 侧链用 MDAnalysis `analysis.dihedrals.Janin`。
- [x] **MM-PBSA / 自由能（§8）**：**主路径 = gmx_MMPBSA + per-residue decomposition + IFP 占比三角**（避免把单一 ΔG 数字当真理）；MM-PBSA 误差 ±2–10 kcal/mol 只支持定性 ranking，ε_in = 4-8 + charmm_radii；alchemical RBFE（WT→V138R 蛋白侧突变，GROMACS 2024 AWH）作 stretch goal。gmx_MMPBSA 原生支持 CHARMM-ff + 膜蛋白官方示例。
- [x] **ascaroside 类比（§9）**：**重大红利** — CHARMM36 carbohydrate (par_all36_carb) **已原生覆盖 fucose/rhamnose**（ascarylose = 3,6-dideoxy-L-mannose 的最近类比）；脂肪酸链 + α-O-glycoside 桥都在 CGenFF drug-like 覆盖范围（CB1 + anandamide 系列 "all very low penalties"）；**分阶段行动计划 2-5 周**（若 penalty 扫描全 <50 可缩至 ~2 周）；端到端模板 = [CB1 ZCZ011 ACS Bio Med Chem Au 2025](https://pubs.acs.org/doi/10.1021/acsbiomedchemau.5c00169)。
