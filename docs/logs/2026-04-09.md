## §2 R6.45 BW 编号排查（#2 任务）

### 背景

config.yaml 中 ARG395 标注为 R6.45（沿用 Hu2024 原文），但 BW 算术给出 6.55 而非 6.45。需确认正确编号。

### GPCRdb 查询结果

GPCRdb **不收录 C. elegans GPCR**。三个受体（GprC/Gpr2/Gpr3）的 UniProt ID 均无结果。C. elegans SRX/SRBC 趋化受体与脊椎动物 GPCR 序列相似度极低，BLAST 转移也不可行。

### GprC TM6 序列分析

WxP motif 确认：W388-I389-**P390**（P6.50 anchor）。以此推算 TM6 BW 编号：

```
385  ILE  6.45
386  LEU  6.46
387  LEU  6.47
388  TRP  6.48  ← W of WxP ✓
389  ILE  6.49
390  PRO  6.50  ← anchor ✓
391  GLY  6.51
392  ILE  6.52
393  ILE  6.53
394  ASN  6.54
395  ARG  6.55  ← TM6 唯一 ARG
```

W6.48=TRP388 验证了 P6.50=PRO390，算术链完整。6.45=ILE385（非 ARG），ARG395=6.55。

### Hu2024 原文确认（p.1759）

原文使用标准 BW（"the most conserved residue... denotes it as number 50"），确认 D2.50、P6.50(GprC/SRBC64)。原文称 "the arginine R6.45 points to the binding site"。

### 矛盾与可能解释

| 假设 | 内容 | 可能性 |
|------|------|--------|
| (a) Hu2024 BW 标记有误 | 实为 R6.55；6.55 在胞外侧，与 "points to binding site" 功能描述一致 | 较高 |
| (b) 我们的分析有误 | TM6 存在 bulge/insertion 使算术偏移；或 P6.50 锚定有误 | 较低但不可排除 |
| (c) 非标准编号惯例 | Hu2024 对非脊椎动物 GPCR 采用了变体 BW 规则 | 低，原文明确描述标准 BW |

**反对 (b) 的证据**：W6.48=TRP388 独立验证了 P6.50=PRO390，两个锚点互相印证。

**无法完全排除 (b) 的原因**：GPCRdb 无法交叉验证；C. elegans GPCR 的 TM6 螺旋是否存在结构 bulge 未知；结构叠合验证尚未执行。

### 决策

- **残基身份（ARG395）和功能角色（ascr18 选择性、突变致亲和力下降）已确认**，不受 BW 编号影响
- config.yaml key name 保留 `R6_45` 与 Hu2024 原文一致，desc 注明争议
- 如需最终确认：对 GprC AF2 结构与 Class A 模板（如 β2AR）做结构叠合，直接比对 TM6 残基

### 验证

- `Grep HU2024_RESIDUES|MUTANT_PDBQTS` 全 codebase 零匹配
