# 2026-07-15 工作日志

## P0 ODE：Phase 0 最小 solver

### 本轮范围

按 [ODE 第一周计划](../../codex/docs/plans/ode-weekly-plan-2026-07-13.md) 实现“理解 + 最小 solver”中的代码部分。范围严格限于一个归一化、单输入、`scenario_prior` 的示意 time-course；不执行剂量响应、1/2/4 copy、leak/动态范围或灵敏度扫描。

### 新增实现

- `src/modeling/ode/minimal_solver.py`：以 SciPy 的 `solve_ivp` 求解 `G_on`、lumped MAPK `M` 与色素 `C`；受体 `R_active`、sTF `TF` 与 GAL product rate 为显式代数接口。链路为 `ligand -> Gpr -> chimeric Gpa1 -> MAPK -> sTF -> GAL -> color`。
- `src/modeling/ode/run_minimal_solver.py`：读取 config 并导出可自描述的 time-course CSV。
- `experiments/ode-model/configs/minimal_normalized_scenario.json`：单一归一化输入的最小场景。顶层 `evidence_status` 强制为 `scenario_prior`，每个模块同时保留其参数状态。
- `tests/modeling/test_ode_minimal_solver.py`：覆盖单情景 time-course、确定性、上游受体信号对输出的影响、CSV 导出和配置边界。

### 边界与证据状态

- config 内的数值只用于验证求解器接口和示意时间尺度；它们不是项目真实浓度、受体亲和力、速率常数、检测限或最佳构型。
- solver 不读取、也不接受 docking `ΔG` 作为 `Kd`、`EC50`、`kon/koff` 或其他动力学输入。
- MAPK 在本轮仅保留为一个 lumped `M` 状态；Shaw/Kofahl/Yi 的详细动力学常数仍须完成 source-table、单位和 kinetic-law 映射后才能考虑进入后续模型。
- 已生成 `experiments/ode-model/results/minimal_normalized_timecourse.csv`，但它只是单一 `scenario_prior` 的可复现示意输出，不能解释为项目预测结果；阶段 1 才能在审阅后生成带参数边界的扫描结果包。
