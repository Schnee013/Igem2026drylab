#### 踩坑记录（SSH 启动过程）

**坑 1**：`Set-Content` 写 bat 文件时 `\r\n` 被当成字面量，bat 文件变成一整行。  
→ 改用 `copy run_s1.bat run_s2.bat` + PowerShell `Set-Content` 替换最后一行。

**坑 2**：bat 文件 `set PATH=...;%%PATH%%` 中 `%%PATH%%` 被 Mac bash 展开成完整路径，导致 cmd 中出现 `%C:\...\bin%` 字符被解析为未知变量名而丢失。  
→ 直接复制 S1 bat（已有硬编码完整 PATH），只替换最后一行 python 命令。

**坑 3**：`Start-Process` 启动的 Python 进程在约 30 秒内静默退出（.err 为空）。  
→ 根本原因：Start-Process redirect pipe 关闭时 Python StreamHandler 写 stdout 失败静默退出。  
→ 解法：改用同步 SSH 背景任务（与 S2 相同方式），SSH 连接保持进程存活。

**坑 4**：S3 运行后 `mutagenesis_results.json = []`，无对接结果。  
→ 根本原因：`experiments/docking-repro/prepared/ligands/` 目录为空，缺少 ascr18/ascr3 PDBQT。  
→ 解法：从 v2 路径 `experiments/docking/prepared/ligands/` 复制两个配体 PDBQT。

**坑 5**：`prepare_receptor.py` 等依赖文件未同步到 Windows（只有 mutagenesis.py 等被同步）。  
→ 解法：手动 `scp` prepare_receptor.py, prepare_ligand.py, run_pipeline.py, validate.py。
