## 踩坑

- 配体几何、prepared 路径、文件命名和 WT/mutant 协议必须由同一配置与 preflight 约束；文件存在或数值自洽都不能证明使用了预定输入。
- Windows `Start-Process` 的重定向管道关闭可使 Python 日志进程静默退出；ADFR 调用需设置 `cwd` 并传文件名，runner 需记录 traceback。
