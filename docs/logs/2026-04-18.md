## Session 3: PPM 版本决策

### 方法学决策：PPM 版本分线记录

| Pipeline | PPM 版本 | 理由 |
| -------- | ------- | ---- |
| 突变体 MD（M327A/M327D） | **PPM 2.0**（保持不变） | 单链 GPCR + 配体，无多链变换需求；membrane build 已完成，不重做 |
| Chimeric MD（Ch1–Ch4） | **PPM 3.0**（切换） | GPCR + Gα 多链复合体；PPM 3.0 整体统一变换更准确；Ch1 本已需重提 |

两线混用 PPM 版本在方法学上可接受，原因：

- **两线不作跨线比较**：突变体线回答"配体结合口袋变化"，chimeric 线回答"GPCR-Gα 界面兼容性"，结论相互独立，不存在需统一 PPM 版本才能成立的对比
- **线内比较用同一版本**：突变体线内（M327A/M327D/WT）全部 PPM 2.0；chimeric 线内（Ch1–Ch4）全部 PPM 3.0；线内一致性有保障
- **CHARMM-GUI 平衡步骤会重新弛豫位置**：PPM 给出初始取向后，NVT/NPT 平衡（带位置限制）会根据能量重新优化，版本间微小倾斜角差异不传导至生产 MD
- **PPM 2.0 对单链 GPCR 与 3.0 无实质差异**：3.0 核心改进是多链复合体统一变换矩阵，单链 GPCR 的疏水板定位算法两版本相同

方法 § 分别注明：突变体用 PPM 2.0，chimeric 用 PPM 3.0，并附上述理由。

#### Ch-2 (C15) EM 未收敛说明（2026-04-19 补记）

**原始日志**：[`experiments/md-simulation/systems/chimeric-gpr3-aogpa2-c15/gromacs/em.log` L47120–47127](../../../experiments/md-simulation/systems/chimeric-gpr3-aogpa2-c15/gromacs/em.log#L47120)

```text
Energy minimization reached the maximum number of steps before the forces
reached the requested precision Fmax < 1000.
Steepest Descents did not converge to Fmax < 1000 in 5001 steps.
Potential Energy  = -4.9247075e+06
Maximum force     =  4.1143779e+03 on atom 61541
Norm of force     =  1.6201559e+01
```

**读法**：`Maximum force` = 体系中受力最大的单个原子的力（kJ/mol·nm），收敛标准是 <1000；`Norm of force` = 所有原子力的 RMS，反映全局弛豫程度。这里 Norm=16.2 极低（全局好），只有 atom 61541 一个点卡住（力=4114）。

**未收敛原因**：Steepest Descents 5001 步达上限，问题原子 = 残基 1229 POPC C210（sn-2 脂肪酸链中段）。C15 是四个体系中最大的（366k 原子，537 POPC），CHARMM-GUI lipid packing 在大体系偶尔留下脂质链局部重叠，SD 步长受全局最大力限制收敛慢。

**EQ 阶段自愈，无需重跑**：step6.1 NVT 正常完成（T=303 K，无 LINCS/SETTLE 错误），step6.6 末态 T=303.2 K、P=-0.6 bar，正常收敛。CHARMM-GUI 6-step 逐步松绑位置限制的过程已将该脂质弛豫到合理构象。step6.6.cpt 可直接用于生产 MD。
