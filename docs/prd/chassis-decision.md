# 底盘选择深度分析: 酵母 vs 丝状真菌

> 来源: PRD v3 §2C, §2D | 最后更新: 2026-04-11
>
> **决策状态**: 已决定（2026-04-11）—— 策略 B（*S. cerevisiae* + STE2 通路 + 嵌合 Gpa1 + 基因组整合）。详见下文 [§最终决策](#最终决策2026-04-11)。

## 最终决策（2026-04-11）

| 项 | 决定 |
|---|------|
| 底盘 | *Saccharomyces cerevisiae*（酿酒酵母） |
| 通路 | STE2 pheromone pathway（异源 Gpr 接入内源 MAPK） |
| G 蛋白 | 嵌合 Gpa1（C 端嫁接真菌来源 Gα C 端，模板 Hara 2012 / Medici 1997） |
| 拷贝数策略 | **基因组整合**（不使用 CEN/2μ 质粒），保证下游显色级联拷贝数稳定 |
| 显色输出 | TBD（报告基因类型、整合位点、是否 GAL4 放大均待定） |

**决策依据**：

1. **PI 确认**：2026-04-11 与 PI 当面讨论后锁定酵母主线。
2. **真菌底盘工具不成熟**：Kuo 2024 / Hu 2024 提示 *A. oligospora*、*A. flagrans* 原生表达体系遗传操作繁琐，CRISPR 工具未稳定建立，周转 ≥1-2 周。
3. **酵母 GPCR 工程模板齐全**：Lengger 2020 综述、Mukherjee 2025 真菌 GPCR 在酵母筛选、Hara 2012 / Medici 1997 嵌合 Gpa1 设计、Fan & Yuan 2024 GAL4 级联放大均已为酵母路线背书。
4. **基因组整合**：避免 CEN/2μ 质粒拷贝数漂移破坏下游显色级联线性度，确保田间读出稳定。

**下游影响（建模方向调整）**：

| 影响项 | 变更 |
|---|---|
| P3 嵌合 Gpa1 同源建模 | priority **P3 → P0**（从备选升至核心，[P3-chimeric-gprotein](../modeling/P3-chimeric-gprotein.md)） |
| P0 信号通路 ODE | 走完整酵母 STE2 ODE（参数源 Shaw 2019 / Fan&Yuan 2024 / Ladds 2005），新增拷贝数敏感性分析 |
| P2 生物防治 LV | not_started → **archived**（仅丝状真菌底盘下激活，[P2-biocontrol-lv](../modeling/P2-biocontrol-lv.md)） |
| 所有下游模型 | 默认基线"基因组单拷贝整合" |
| 显色级联 | 不进入建模，作为 TBD 占位（待报告基因方案确定后回填） |

## 核心技术挑战

**所有下游工程（显色输出、放大回路、产品化）都是有解的工程问题。** 整个项目成败的决定性环节是:

> **Gpr 受体能否在底盘生物中正确折叠、定位到细胞膜、并与下游 G 蛋白功能性偶联？**

这一个问题，决定了底盘选择的全部逻辑。

## 酵母方案的逻辑链

```
优势链:
  酵母 GPCR 工程极其成熟 (Ste2/Ste3 pathway)
  → pheromone pathway 每个节点都有定量参数
  → 建模数据充足
  → 遗传操作快速（2-3 天周转）
  → iGEM 社区熟悉，评审友好
  → 冻干酵母试纸产品化路径清晰

核心风险:
  Gpr2/3/GprC 来自丝状真菌
  → 七跨膜结构与酵母内源 GPCR 差异大
  → 异源表达后能否正确插膜？→ 未知
  → 能否与嵌合 Gpa1 偶联？→ 未知
  → 这是整个方案的"0 或 1"风险点
  
缓解措施:
  → 嵌合 G 蛋白设计有先例
  → Fan & Yuan 2024 方案可作为模板
  → 分子对接和嵌合蛋白建模（§3.1, §3.6）可在湿实验前筛选最优设计
```

## 丝状真菌方案的逻辑链

```
优势链:
  Gpr 受体在 A. oligospora / A. flagrans 中原生表达
  → 折叠、膜定位、G蛋白偶联全部已知可行
  → "0 或 1"风险直接消除
  → 叙事强大: "用线虫天敌来检测线虫"
  → 如果实验室有操作基础 → 巨大竞争优势

核心风险:
  1. 遗传操作成熟度远低于酵母（CRISPR 不如酵母稳健，周期 1-2 周 vs 2-3 天）
  2. 通路参数匮乏，ODE 建模困难（只能做粗粒度 Hill 函数近似）
  3. 响应型启动子未知（需 RNA-seq 数据或文献推测）
  4. 产品化路径不清晰（不像酵母容易冻干成试纸）
```

### 策略 A（丝状真菌主线）

## 关于"并行"的审慎评估

**并行的成本是真实的，收益是不确定的。**

- 6 个月实际可用建模时间约 3-4 个月
- 并行 = 两套通路、两套建模、两套显色优化
- 建议: 除非湿实验 ≥6 人，否则**第 4 周前确定主线**，另一个作为 backup
