## 2. 田间线虫防治现状与痛点

### 2.1 现有防治手段

| 手段 | 优势 | 痛点 |
|------|------|------|
| 化学杀线虫剂 | 短期效果显著 | 大量有效药物因毒性被禁/限用；微生物降解；残留 |
| 抗性/耐性品种 | 不施药、环保 | 并非所有作物有；连续种植会选择突破抗性的株系 |
| 轮作与覆盖作物 | 低成本、可持续 | 需精确知道线虫种类；杂草替代宿主削弱效果 |
| 生物防治 | 环保、可持续 | 田间效果不稳定、起效慢、受土壤环境影响大 |
| 土壤熏蒸/日晒 | 广谱杀灭 | 甲基溴已禁；日晒杀有益微生物；塑料废弃物 |
| 综合管理（IPM） | 理论最优 | **需要精确诊断线虫种类和数量 — 恰恰是最大瓶颈** |

### 2.2 核心痛点链

所有防治手段都依赖一个前提: **你得先知道地里有什么线虫、有多少**。

```
1. 发现太晚 → 地上症状在早期不明显，发现时种群已建立
2. 诊断太慢太贵 → 送实验室 2 周，需专业分类学家（正在减少）
3. 物种鉴定困难 → 种间形态重叠，混合感染
4. 防治窗口窄 → 多数手段是预防性的，需在感染早期介入
5. 有效药物在减少 → 化学杀线虫剂逐步禁用，新药注册周期长
```

### 2.3 项目价值定位

> 价值不是"发明新防治方法"，而是 **"解决防治链条上最关键的第一步——快速、低成本、田间原位的早期检测"**。让现有所有防治手段都能发挥更大作用。

### 2.4 项目叙事链路

```
检测到信号 → 推断线虫密度范围（贝叶斯模型）
                    │
                    ├── 低风险 → 建议: 继续监测
                    ├── 中风险 → 建议: 轮作/覆盖作物/生物防治
                    └── 高风险 → 建议: 化学干预 + 具体药剂浓度
                                  ↓
                    经济效益模型量化"提前检测省了多少钱"
```

## 3. 防治建模方向决策

### 决策原则（iGEM 比赛视角）

1. **可建模、有数据**: 能做出定量预测
2. **不需要动物/田间实验验证**: 没有条件做
3. **能完成"检测→建议"闭环叙事**: 评审看到完整 DBTL + Proposed Implementation
4. **与检测系统耦合度高**: 检测信号能直接输入防治决策模型

### 三条路线评估

| 路线 | 数据可获取性 | 建模难度 | 叙事价值 | 耦合度 | **推荐度** |
|------|-------------|---------|---------|--------|-----------|
| (a) 化学杀线虫剂剂量-响应 | ★★★★★ | ★☆☆☆☆ | ★★★☆☆ | ★★★★★ | **中高** |
| (b) 生物防治 Lotka-Volterra | ★★★☆☆ | ★★☆☆☆ | 条件性★★★★★ | ★★★☆☆ | **仅丝状真菌底盘** |
| (c) 早期检测经济效益 | ★★★★★ | ★☆☆☆☆ | ★★★★★ | ★★★★★ | **最高优先** |

### 最终决策

- **必做**: (c) [经济效益模型](../modeling/P2-economic-benefit.md) — 最短路径、最高性价比
- **推荐做**: (a) [剂量-响应模型](../modeling/P2-dose-response.md) — 技术角度闭环；底盘=酵母后从"选做"升为推荐
- **不激活**: (b) [生物防治 LV](../modeling/P2-biocontrol-lv.md) — 2026-04-11 底盘锁定酵母后失去叙事耦合，方向归档
