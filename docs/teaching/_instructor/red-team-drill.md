# 红队演练流程
> **用途**：组会上扮演评委追问成员的实操手册。题目从 `qa-bank.md` 抽取，本文件只管"怎么演练"，不重复题目本身。
## 1. 抽题规则
### 分阶段抽题
按成员当前学习进度，只从已覆盖的文档对应的主题组里抽：
| 成员已学完 | 可抽的主题组 | 题数 |
|-----------|------------|------|
| DO-1 + KNOW-1 | 主题 0（电梯陈述）+ 主题 1（定位）+ 主题 2（方法） | 15 题 |
| DO-2 + KNOW-2 | 加入主题 3（pipeline）+ 主题 4（统计） | +15 题 |
| DO-3 + KNOW-3 | 加入主题 5（结果）+ 主题 6（迭代）| +8 题 |
| 全部 + DO-4 + KNOW-4 | 全题库 + 主题 7（兜底） | 43 题 |
### 全题库随机
模拟答辩时从 43 题里随机抽 10 题，不按主题分组。
### 抽取方式
```python
import random
# 全题库随机抽 10 题
questions = list(range(1, 44))  # Q0.1-Q0.3 算 1-3，Q1 算 4，以此类推
random.sample(questions, 10)
```
或者更简单：把题号写纸条放碗里抽。
## 2. 演练规则
### 时间限制
- **每题 90 秒**（用手机计时器）
- 90 秒到了必须停，不管答没答完——答辩现场评委不会等你
- 电梯陈述（Q0.1）特殊：**严格 60 秒**
### 追问节奏
每题结束后可以追问 1-2 次（模拟评委"挖一层"的习惯）。追问不额外计时，但成员应该在 30 秒内给出回应。
### 一轮的流程
1. 抽 5-10 题
2. 逐题计时回答
3. 每题结束后你给即时反馈（10 秒：对了什么 / 漏了什么）
4. 全部做完后总结（见 §4）
## 3. 扮演评委的话术提示
### 严厉追问
- "你刚才说了 X，但这不就是在重复文献吗？你们的增量到底在哪？"
- "0.48 kcal/mol 作为阈值，Vina 的精度才 ±1，你怎么解释？"
- "你说 V138R 有盐桥，但你有证据吗？"
- "AF3 预测的结构你也敢用？pLDDT 多少？"
### 打断
- 成员讲到 30 秒时打断："好，我理解了。那你告诉我 [下一个追问]"
- 打断的目的：训练成员在被中断后能快速切换话题而不卡壳
### 假设性质疑
- "假如 Hu2024 的 ΔG 数值本身就不准，你的 Δ=0.05 还有意义吗？"
- "假如湿实验做出来 V138R 不 work，你怎么解释？"
- "假如换一个 seed，你的 Top 6 会不会完全不同？"
### 友善但危险的问题
- "这个 pipeline 你觉得最大的弱点是什么？"（陷阱：如果成员只列弱点不给承接路径，就输了）
- "如果再给你一个月，你最想改什么？"（陷阱：如果说"换更好的方法"就暴露了对协议一致性的不理解）
## 4. 卡壳时的引导式重启
成员卡壳超过 10 秒时，不要直接告诉答案。用以下话术引导：
| 卡壳类型 | 引导话术 |
|---------|---------|
| 完全不知道 | "先想一下，这个问题涉及的是哪份文档的内容？" |
| 知道大方向但说不清 | "你先说结论，再给我一条支持这个结论的证据" |
| 数字记不住 | "数字不记得没关系，先讲逻辑——阈值是怎么定的？" |
| 说错了关键事实 | 不要当场纠正——记下来，全部做完后在 §4 总结时统一纠正 |
**不要当场纠正**的原因：答辩现场评委不会纠正你，成员需要训练的是"说错了也能自然地继续讲下去、事后修正"的能力，而不是"被纠正后重新来一遍"。
## 5. 演练后反馈
### 即时反馈（每题结束后 10 秒）
- "核心论据到了 / 没到"
- "数字准确 / 有偏差"
- "追问回应顺畅 / 卡了"
### 总结反馈（全轮结束后 5-10 分钟）
1. **哪些题答得好**：具体说哪一条论据讲得清楚
2. **哪些题需要回去重读**：给出 v2 文档编号和章节号（如 KNOW-2 §4）
3. **关键事实纠错**：把演练中说错的事实逐一纠正（此时才纠正，不是演练中）
4. **下次重点**：从本轮最弱的 2-3 题开始下次演练
### 记录
建议每次演练后在飞书笔记里记一行：日期 / 抽了哪些题 / 通过几题 / 最弱的 2-3 题编号。这样可以追踪进步。
