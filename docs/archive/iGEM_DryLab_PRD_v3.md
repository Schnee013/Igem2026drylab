## 1. 项目全貌

### 1.1 一句话描述

构建一个**基于 GPCR 生物传感器**的植物寄生线虫田间早期检测系统：线虫分泌特征性蛔苷素（ascarosides）→ 捕食性真菌来源的 Gpr 受体感知 → 底盘生物（**酿酒酵母或丝状真菌，待定，可能并行**）信号转导与级联放大 → 肉眼可见的显色输出 → 防治建议闭环。

> **底盘决策状态：** 尚未最终确定。酵母方案文献支持充足、改造成熟；丝状真菌方案有 PI 实验室支持，Gpr 受体为原生表达，无需异源偶联。两者建模策略差异显著（见 §3）。**v3 新增：** 详细的第一性原理分析见 §2C，决策树见 §2C.4，决策的阻塞性前置信息见 §2D。

### 1.2 核心信号链路

```
土壤中有害线虫 (PPNs)
    │ 分泌
    ▼
ascr#18 / ascr#3（特征比例）
    │ 配体结合
    ▼
Gpr2 / Gpr3 / GprC（来自 A. oligospora / A. flagrans）
    │
    ├─── 方案 A: 异源表达于酵母膜 ──┐
    │    嵌合 Gpa1 → MAPK 级联      │
    │    GAL4 正反馈放大              │
    │                                 │
    ├─── 方案 B: 丝状真菌原生表达 ──┤
    │    内源 MAPK/PKA 通路           │
    │    寻找响应启动子               │
    │                                 │
    ▼                                 │
显色蛋白 (Lycopene / Betalain / amilCP)◄┘
    │
    ▼
田间可视化判读 → 防治建议闭环
```

### 1.3 双靶标判别逻辑

- **ascr#18：** 在植物寄生线虫（PPNs）中占绝对优势
- **ascr#3：** 在自由生活线虫中占主导
- 通过改造 Gpr 受体获得对 ascr#3 / ascr#18 的差异化特异性，双信号比例判别有害线虫

## 2. 干实验现有想法与审慎评估

### 2.1 原有方向

| 方向 | 描述 | 评估 |
|------|------|------|
| 方向 A | 从土壤样本线虫标志物浓度预测土壤线虫丰度 | ✅ 合理，但受限于 ascr 分泌速率定量数据的可获取性（1.1 中提到"目前查不到"） |
| 方向 B | 建模杀虫/防治物质对实际生产环境中的效果预测 | ✅ **修正评估：合理且必要。** 项目叙事为"检测→预防"闭环，由于无法进行动物实验，干实验预测是完成此闭环的唯一途径。需要进一步明确：(a) 防治手段是什么（生物防治/化学农药/抗性品种）？(b) 建模对象是什么（药物-靶标动力学？种群抑制动力学？田间扩散效率？） |

### 2.2 核心问题

**方向 A 的瓶颈：** 目前文献中可能没有 ascr#18 / ascr#3 在田间真实条件下的精确分泌速率数据（fmol/worm/h）。建议将此模型设计为参数化/敏感性分析框架（即："如果分泌速率在 X–Y 范围内，则检测灵敏度如何变化"），而非追求单一精确映射。

**方向 B 的待明确项：** "杀虫物质"具体指什么？以下是几种可能的建模对象及其可行性：
- **(a) 化学杀线虫剂的种群动力学**：建模不同药剂浓度下线虫种群的抑制/恢复曲线。数据来源：已发表的 LC50/EC50 文献。**可行性高。**
- **(b) 生物防治（捕食性真菌）的捕食效率**：建模 *A. oligospora* 捕食网形成速率与线虫密度的关系。文献基础较好。**可行性中等。**
- **(c) 抗性品种的损失规避建模**：经济学模型，计算"早期检测+抗性品种替换"相比"不检测"的损失差异。**可行性高，且对 HP 叙事价值大。**

**⚡ 建议：** 优先选 (a) 或 (c)，它们数据可获取性好，且与"检测系统"的耦合度高。需要与 HP 组讨论确定。

## 2A. 田间线虫防治现状与痛点调研（基于文献检索，2026-04-02）

> 本节为 v3 新增内容，目的是为"防治闭环"建模方向提供事实基础，并明确项目叙事中"我们的检测系统为什么有价值"的论证素材。

### 2A.1 现有防治手段概览

根据文献调研，当前植物寄生线虫（PPNs）的管理手段包括以下几大类：

| 手段 | 原理 | 优势 | 痛点 |
|------|------|------|------|
| **化学杀线虫剂** | 阿维菌素、噻唑膦、氟吡菌酰胺等 | 短期效果显著 | 大量有效药物因环境毒性被禁/限用；微生物降解导致连续使用效果下降；残留问题 |
| **抗性/耐性品种** | 培育抗线虫入侵或耐受损害的作物品种 | 不施药、环保 | 并非所有作物有抗性品种；连续种植同一抗性品种会选择出突破抗性的线虫株系 |
| **轮作与覆盖作物** | 种植非寄主作物打断线虫生活史 | 低成本、可持续 | 需要精确知道线虫种类才能制定轮作方案；杂草作为替代宿主会削弱效果 |
| **生物防治** | 捕食性真菌（*A. oligospora*）、寄生细菌（*Pasteuria*）、菌根真菌等 | 环保、可持续 | 田间效果不稳定、起效慢、受土壤环境影响大 |
| **土壤熏蒸/日晒** | 甲基溴（已禁）、生物熏蒸（芥菜属植物）、土壤日晒灭杀 | 广谱杀灭 | 甲基溴已全面禁用；日晒同时杀死有益微生物；产生塑料废弃物 |
| **综合管理（IPM）** | 多种手段组合 | 理论最优 | 需要精确诊断线虫种类和数量，而这恰恰是最大瓶颈 |

### 2A.2 核心痛点链：为什么现有防治方案在实际生产中效果有限？

从第一性原理出发，所有防治手段都依赖一个前提条件：**你得先知道地里有什么线虫、有多少**。而这一步恰恰是整个防治体系最薄弱的环节：

```
痛点链：

1. 发现太晚
   └─ 线虫主要损害根部，地上症状在早期不明显
   └─ 农户通常在产量明显下降后才注意到问题
   └─ 此时线虫种群已经建立，防治成本和难度大幅增加

2. 诊断太慢、太贵
   └─ 传统方法：采集土壤/根系样本 → 送实验室 → 形态学/分子鉴定 → 约 2 周出结果
   └─ 需要受过训练的线虫分类学家，而这类专家全球范围内正在减少
   └─ 分子诊断（PCR、qPCR）虽更快，但仍需实验室设备，不适合田间原位检测

3. 物种鉴定困难
   └─ 线虫种间形态重叠大、种内变异大
   └─ 不同物种的经济阈值不同，错误鉴定会导致错误的管理决策
   └─ 混合感染（多物种共存）进一步增加诊断复杂度

4. 防治窗口窄
   └─ 一旦线虫感染植物根系，几乎无法逆转
   └─ 大多数防治手段是预防性的，需要在种植前或感染早期介入
   └─ "种植前施药"的策略在不知道线虫存在的情况下是盲目的、浪费的

5. 有效药物在减少
   └─ 化学杀线虫剂因毒性和环境问题被逐步禁用
   └─ 新药注册门槛高、周期长
   └─ 生物防治作为替代方案效果不够稳定
```

**关键洞察：** 你们项目的价值定位不应该是"我们发明了一种新的防治方法"，而是 **"我们解决了防治链条上最关键的第一步——快速、低成本、田间原位的早期检测"**。检测系统本身不需要自己做防治，它的价值在于让现有的所有防治手段都能发挥更大作用（因为介入更早了）。

### 2A.3 对项目叙事的启示

项目的 Proposed Implementation 叙事应该是：

```
检测到信号 → 推断线虫密度范围（贝叶斯模型，§3.4）
                    │
                    ├── 低风险（低于经济阈值）→ 建议：继续监测，下次采样时间 T
                    ├── 中风险 → 建议：轮作非寄主作物 / 种植覆盖作物 / 施用生物防治菌剂
                    └── 高风险（远超阈值）→ 建议：化学干预 + 具体药剂和施用浓度参考
                                              ↓
                              经济效益模型（§3.5c）量化"提前检测省了多少钱"
```

这个叙事不需要你们自己做防治实验，但需要干实验提供定量支撑。

## 2B. 防治干预手段决策：iGEM 比赛视角下的最优选择

> **核心问题：** PRD §3.5 列出了三条防治建模路线 (a)(b)(c)，现在需要明确选哪条、为什么。

### 2B.1 决策原则

作为 iGEM 比赛项目（而非真正投入生产的系统），干预手段的选择应该满足：

1. **可建模、有数据**：干实验能做出定量预测，而非空洞的"建议使用 XX"
2. **不需要动物/田间实验验证**：你们没有条件做
3. **能完成"检测→建议"闭环叙事**：评审能看到完整的 Design-Build-Test-Learn + Proposed Implementation
4. **与检测系统耦合度高**：检测信号的定量值能直接输入防治决策模型

### 2B.2 三条路线的重新评估

| 路线 | 数据可获取性 | 建模难度 | 叙事价值 | 与检测系统耦合度 | **推荐度** |
|------|-------------|---------|---------|------------------|-----------|
| **(a) 化学杀线虫剂剂量-响应** | ★★★★★（LC50/EC50文献丰富）| ★☆☆☆☆ | ★★★☆☆ | ★★★★★（检测信号→密度→施药浓度） | **中高** |
| **(b) 生物防治效率 Lotka-Volterra** | ★★★☆☆ | ★★☆☆☆ | ★★★★☆（如果底盘是丝状真菌则 ★★★★★）| ★★★☆☆ | **条件性：仅丝状真菌底盘时推荐** |
| **(c) 早期检测经济效益** | ★★★★★（作物损失函数文献大量存在）| ★☆☆☆☆ | ★★★★★（直接支撑 HP 和 Proposed Implementation）| ★★★★★ | **最高优先** |

### 2B.3 最终建议

**必做：(c) 经济效益模型** — 这是完成"检测→预防"闭环叙事的最短路径、最高性价比选择。

- 输入：作物损失函数（线虫密度 vs 产量损失百分比，Sasser & Freckman 1987 经典综述 + 后续更新），检测试剂成本估算，各防治手段成本文献值
- 输出："无检测 vs 早期检测+干预"两种情景下的成本-收益对比，ROI 曲线，"每提前 X 天检测可减少 Y% 经济损失"
- 难度极低，纯算术建模，1-2 周内可完成
- 对 HP 组价值极高，可以直接用在与农业专家、政策制定者的访谈中

**选做（推荐）：(a) 剂量-响应模型** — 提供"检测到什么信号建议施多少药"的定量链。

- 从文献收集 2-3 种常用杀线虫剂（阿维菌素、噻唑膦、氟吡菌酰胺）对 *M. incognita* / *H. glycines* 的 LC50/EC50
- 建 Hill/log-logistic 剂量-响应模型
- 与 §3.4 的密度推断模型串联：传感器信号 → 线虫密度后验分布 → 推荐施药浓度范围
- 难度低，数据拟合为主

**条件性推荐：(b) 生物防治 Lotka-Volterra** — **仅在底盘最终选丝状真菌时才值得做**。

- 理由：如果底盘是 *A. oligospora* 或近缘物种，叙事变为"我们用线虫天敌来检测线虫，同时还能预测这种天敌在田间的防治效果"，形成从检测到防治的完整生物闭环
- 如果底盘是酵母，此模型与项目主体没有直接关联，做了也是"附加的背景分析"，投入产出比低

## 2C. 底盘选择深度分析：酵母 vs 丝状真菌

> **决策状态：** 未确定。本节从第一性原理出发分析两条路线的技术逻辑，并给出需要确认的前置信息和决策流程。

### 2C.1 核心技术挑战再定义

**所有下游工程（显色输出、放大回路、产品化）都是有解的工程问题。** 整个项目成败的决定性环节是：

> **Gpr 受体能否在底盘生物中正确折叠、定位到细胞膜、并与下游 G 蛋白功能性偶联？**

这一个问题，决定了底盘选择的全部逻辑。

### 2C.2 两条路线的技术逻辑

#### 酵母方案的逻辑链

```
优势链：
  酵母 GPCR 工程极其成熟 (Ste2/Ste3 pathway)
  → pheromone pathway 每个节点都有定量参数
  → 建模数据充足
  → 遗传操作快速（2-3 天周转）
  → iGEM 社区熟悉，评审友好
  → 冻干酵母试纸产品化路径清晰

核心风险：
  Gpr2/3/GprC 来自丝状真菌
  → 七跨膜结构与酵母内源 GPCR (Ste2/Ste3) 差异大
  → 异源表达后能否正确插膜？→ 未知
  → 能否与嵌合 Gpa1 偶联？→ 未知
  → 这是整个方案的"0 或 1"风险点
  
缓解措施：
  → 嵌合 G 蛋白设计（Gpa1 C端替换为真菌 Gα C端）有先例
  → 可以用 Fan & Yuan 2024 的方案作为模板
  → 分子对接和嵌合蛋白建模（§3.1, §3.6）可以在湿实验之前筛选最优设计
```

#### 丝状真菌方案的逻辑链

```
优势链：
  Gpr 受体在 A. oligospora / A. flagrans 中是原生表达的
  → 受体折叠、膜定位、G蛋白偶联 → 全部是已知可行的（文献已证明）
  → "0 或 1"风险直接消除
  → 叙事天然强大："用线虫天敌来检测线虫"
  → 如果实验室有操作 A. oligospora 的基础 → 巨大竞争优势

核心风险：
  1. 遗传操作工具成熟度远低于酵母
     → 丝状真菌转化效率低，细胞壁是主要障碍
     → CRISPR 系统在丝状真菌中可用但不如酵母稳健
     → 一轮 Build-Test 周期长（1-2周 vs 酵母的2-3天）
  
  2. 通路参数匮乏，建模困难
     → 内源 MAPK/PKA 通路的动力学参数几乎没有文献值
     → ODE 模型只能做粗粒度 Hill 函数近似
     → 灵敏度分析的精度受限
  
  3. 响应型启动子未知
     → 需要找到 Gpr 激活后被上调的内源启动子
     → 可能需要转录组数据（RNA-seq），数据可能不存在
     → 或者使用通用的信号通路响应启动子（如 MAPK pathway 下游）
  
  4. 产品化路径不清晰
     → 丝状真菌不像酵母那样容易冻干成试纸形态
     → 田间部署方案需要额外设计
```

### 2C.3 决策的关键前置信息（⚠️ 需要团队确认）

底盘决策**不能**仅通过文献分析完成，必须结合以下实验室内部信息：

| # | 待确认信息 | 为什么重要 | 确认方式 |
|---|-----------|-----------|---------|
| 1 | **实验室做的"真菌"具体是什么物种？** | 如果是 *A. oligospora* 或 *A. flagrans* → 丝状真菌方案风险大幅降低。如果是 *Aspergillus* → 异源表达问题同酵母。如果是 *Trichoderma*/*Neurospora* → 有工具但受体仍需异源表达 | 问 PI |

### 2C.6 关于"并行"策略的审慎评估

PRD v2 中提到"可能并行"两个底盘。需要警惕的是：

**并行的成本是真实的，收益是不确定的。**

- 6 个月时间，考虑到学习曲线 + 湿实验周转 + wiki 撰写，真正可用的建模和实验时间大约只有 3-4 个月

- 对于湿实验：每个底盘至少需要 2-3 轮 DBTL cycle，并行会摊薄每个方案的迭代次数

**建议：** 除非团队人力充足（湿实验 ≥6 人），否则应在**第 4 周前**确定主线底盘，另一个作为 backup 而非并行。干实验可以先用酵母方案建模（数据充足），如果最终切换到丝状真菌，模型框架可以复用、参数替换。

## 3. 干实验方向规划（按优先级排序）

以下方向从**第一性原理**出发，围绕一个核心问题：**你们的检测系统，从土壤中一条线虫到试纸变色，整条链路的每个环节能否被定量预测？** 干实验的价值在于回答湿实验无法回答、或可以在湿实验之前回答的问题。

### 优先级 P0：直接支撑湿实验设计的建模

#### 3.1 受体-配体分子对接与结构分析

**解决什么问题：** 湿实验组需要知道 Gpr2/3/GprC 对 ascr#3、ascr#7、ascr#18 的结合亲和力差异，以及哪些氨基酸残基影响特异性（1.2 和 1.3 任务的直接支撑）。

**方法路线：**
1. 从 AlphaFold DB 获取 Gpr3 (G1XJN1)、Gpr2 (G1X9E2)、GprC (A0A437AGY2) 的预测结构
2. 使用 AutoDock Vina 进行 ascr#18 / ascr#3 与受体的分子对接
3. 分析结合口袋（binding pocket）关键残基
4. 用计算突变扫描（in silico mutagenesis）预测增强特异性的突变位点

**工具栈：** AlphaFold DB / ColabFold, PyMOL, AutoDock Vina, PLIP (蛋白-配体相互作用分析)

**产出：** 受体-配体结合能排名、结合口袋关键残基列表、推荐突变位点

**学习成本：** ★★☆☆☆（有 Python 基础，工具有完善教程）

#### 3.2 信号通路 ODE 建模（双底盘分支策略）

**解决什么问题：** 信号链路的定量预测——系统能检测的最低 ascr 浓度是多少？放大倍数如何选择？背景泄漏对假阳性的影响？

> **v3 更新：** 底盘选择的深度分析见 §2C。建模策略将根据底盘决策结果进入策略 A（丝状真菌主线）或策略 B（酵母主线），见 §2C.4。在底盘确定前，建议先用酵母方案建模（数据充足），模型框架可在切换底盘时复用。

**双底盘策略：**

| 维度 | 酵母方案 | 丝状真菌方案 |
|------|---------|-------------|
| 通路结构 | Gpr → 嵌合Gpa1 → Ste11/Ste7/Fus3 MAPK → GAL4正反馈 → 报告基因 | Gpr → 内源Gα → MAPK/PKA → 内源响应启动子 → 报告基因 |
| 参数可获取性 | ★★★★★ 酵母 pheromone pathway 参数文献极丰富 | ★★☆☆☆ 丝状真菌通路参数稀缺 |
| 建模可行性 | 高：可建立详细的定量 ODE 模型 | 低：更适合定性/半定量分析，或粗粒度 Hill 函数近似 |
| 关键参考 | Shaw et al. 2019 *Cell*; Fan & Yuan 2024 *Biosens. Bioelectron.* | Hu et al. 2024 *Nature Microbiology* |

**建议：** 无论最终选哪个底盘，先用酵母方案建立完整 ODE 模型（数据充足），如果最终选丝状真菌，再做参数迁移或简化版模型。

**方法路线：**
1. 将信号通路拆解为生化反应网络
2. 用质量作用定律和 Hill 函数建立 ODE 模型
3. 参数从文献获取（酵母 pheromone pathway 有大量已知参数）
4. 灵敏度分析：哪些参数对最终输出影响最大？
5. 优化放大回路设计参数

**工具栈：** Python (SciPy, NumPy, Matplotlib), COPASI, PySB

**产出：** 系统剂量-响应曲线、灵敏度极限预测、放大倍数优化建议

**学习成本：** ★★☆☆☆（有 Python 基础，主要学 ODE 建模思路）

**关键参考：** Shaw et al. 2019 *Cell* 中的酵母 GPCR 通路模型可作为直接起点

### 优先级 P1：增强项目叙事完整性的建模

#### 3.3 土壤中 ascaroside 扩散-检测模型

**解决什么问题：** 如果你们的试纸放在田间土壤中，ascarosides 从线虫分泌到接触试纸需要多久？检测有效半径是多少？这直接决定产品部署方案的合理性。

**方法路线：**
1. 建立 ascaroside 在土壤多孔介质中的扩散方程（Fick 定律 + 吸附项）
2. 考虑土壤含水量、有机质含量等参数
3. 模拟不同线虫密度下，试纸周围的 ascr 浓度分布随时间的变化
4. 结合 3.2 的灵敏度极限，计算检测有效半径

**工具栈：** Python (NumPy, SciPy - PDE 求解), FEniCS (如需 3D)

**产出：** 检测有效距离、最优试纸间距建议、从部署到出结果的时间预测

**学习成本：** ★★★★☆（偏难，但方程本身不复杂）

#### 3.4 标志物浓度→线虫丰度推断模型（原方向 A 的改进版）

**改进思路：** 不再追求精确的"浓度→丰度"映射（缺乏数据），改为**贝叶斯推断框架**：给定检测信号强度，线虫种群密度处于什么范围的概率是多少？

**方法路线：**
1. 建立参数化的正向模型：线虫数量 → 分泌速率 → 土壤浓度 → 传感器响应
2. 以分泌速率为不确定参数，设置合理的先验分布
3. 用贝叶斯推断从传感器信号反推线虫密度的后验分布
4. 输出带置信区间的丰度估计

**工具栈：** Python (PyMC, emcee, ArviZ)

**产出：** 概率推断模型、不确定性量化、检测阈值建议

**学习成本：** ★★★★☆（需要学贝叶斯统计基础）

### 优先级 P2：完成"检测→预防"闭环的建模

#### 3.5 防治效果预测模型（原方向 B 的具体化）

**项目叙事定位：** 检测到有害线虫后，系统应当能给出防治建议。由于无法进行田间动物实验，需要干实验补齐"预防"端。

> **v3 更新：** 经过 §2A 痛点调研和 §2B 决策分析，本方向的优先级和路线已明确。结论：**(c) 经济效益模型为最高优先，(a) 为推荐辅助，(b) 为条件性推荐（仅丝状真菌底盘）。** 详见 §2B.3。

**三条可选路线（建议选 1-2 条）：**

**(a) 化学杀线虫剂的种群抑制动力学**
- 方法：从文献收集常用杀线虫剂（如阿维菌素、噻唑膦等）对 *H. glycines* / *M. incognita* 的 LC50/EC50 数据
- 建立 dose-response 模型（Hill/log-logistic）预测不同施药浓度下的种群存活率
- 结合检测系统的定量能力，给出"检测到 X 信号强度 → 建议施药浓度 Y"的决策链
- 工具：Python (SciPy curve_fit), R (drc 包)
- 学习成本：★☆☆☆☆ （最简单，纯数据拟合）

**(b) 生物防治效率建模（如果底盘选丝状真菌）**
- 方法：建立 *A. oligospora* 捕食效率与线虫密度的 Lotka-Volterra 类捕食模型
- 参数来源：Kuo et al. 2024 等文献中的捕食实验数据
- 产出：预测什么线虫密度下生物防治有效，什么密度下需要化学干预
- 学习成本：★★☆☆☆

**(c) 早期检测经济效益模型**
- 方法：建立"无检测 vs 早期检测+干预"两种情景的成本-收益对比模型
- 输入：作物损失函数（线虫密度 vs 产量损失，文献有大量数据）、检测试剂成本、防治成本
- 产出：ROI 分析，量化"每提前 X 天检测，可减少 Y% 产量损失"
- 此模型对 HP 叙事价值极高（经济论证→Proposed Implementation）
- 学习成本：★☆☆☆☆ （基础算术建模）

**建议：** (a) + (c) 并行，数据可获取性最好，且分别从技术和经济两个角度完成闭环。

## 5. iGEM 评审视角下的干实验策略

iGEM 评审对 Model 的核心要求是 **"Model 与湿实验之间有实际的互动"**（model-experiment feedback loop）。建议策略：

1. **P0 中的分子对接** 产出突变位点建议 → 湿实验组据此设计定点突变 → 验证结果反馈回模型 → **完成一个 Design-Build-Test-Learn cycle**
2. **P0 中的通路 ODE 模型** 预测放大回路参数范围 → 湿实验组据此选择 GAL4 promoter 强度 → 测量实际输出 → 用数据校准模型
3. **P1 的扩散模型** 为 Integrated Human Practices 提供定量论据（"为什么试纸间距应该是 X cm"）
4. **P2 的防治效果模型** 完成"检测→预防"闭环叙事，为 Proposed Implementation 提供定量支撑。经济效益模型 (3.5c) 对 HP 组的价值尤其高
