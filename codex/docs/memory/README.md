This directory is retained as a historical set so old references do not break.
It is not a startup route, current-state source, handoff layer, or policy
authority.

Use the active repository routes instead:

- governance and task routing: `docs/DOCMAP.md`;
- project-level current state: `docs/INDEX.md`;
- execution plans and handoffs: `codex/docs/plans/`;
- process history: `docs/logs/`;
- scientific and technical facts: domain docs, code, configs, result files,
  paper summaries, and data outputs.

Any claim found in this directory must be treated as a dated historical
snapshot and recalibrated against those active sources before use.

## Files

- `current-state.md`: timestamped latest snapshot, historical timeline, and source pointers.
- `execution-discipline.md`: reusable workflow, evidence, claim, and code-change discipline.
- `pitfalls.md`: drylab-specific scientific/documentation traps and guardrails.
- `plan-index.md`: relevant Claude plan files and their current interpretation.
- `references.md`: people / external-contact reference notes.

Repo-owned execution plans live in `codex/docs/plans/`. Memory files may point
to those plans but should not duplicate their content.

These files are preserved without claiming that their contents remain current.
Do not update them to follow project changes; add new facts to the active
authority selected by `docs/DOCMAP.md`.
